# Content Pattern (lesson, module, week)

Content lives in two Astro content collections, authored once in EN and shared by all locales:

- **`src/content/lessons/{python-101,data-analysis}/{normal,hard}/*.md`** — the per-track lessons. Frontmatter: `title`, `description`, `module` (grouping id, e.g. `python-basics`, `strings`), `order`, `difficulty`, `estimatedMinutes`, `learningObjectives`, `prerequisites`, plus lesson-wiring flags (`hasPlayground`, `hasQuiz`, `quiz`, `xpReward`). Authored EN-only; the same files serve every locale (thin wrapper page per locale — see [`i18n.md`](./i18n.md)).
- **`src/content/modules/`** — the grouping modules that a lesson's `module` id links to, rendered as separate module pages.

Each lesson body follows a consistent skeleton (rendered by `LessonPage.astro`):
1. **Learning objectives** — the `learningObjectives` frontmatter list rendered as a framed "You'll learn" block.
2. **Runnable examples inline** — Python is written inside the markdown and turned into runnable Pyodide cells by the `rehype-runnable-python` rehype plugin at build time (`RunnableCell`), with **friendly error messages** (traceback → plain-language hint) and dataset auto-mounting (`mountDatasets`, `pda-sec`/`pda::run` signals). See [`playground.md`](./playground.md).
3. **🍵/challenges/reasoning blocks** — collapsible self-check tasks and the "math-first" framing (KaTeX via `rehypeKatex`).
4. **Quizzes** — a `Quiz` component (auto-graded MC/spot-check; `quizCorrect` 5 XP / `quizPerfect` 25) attached via the `quiz` frontmatter when present.
5. **Notebook companion** — `NotebookCell` with Colab/Kaggle/nbviewer/Binder/Deepnote/GitHub launch badges where a `.ipynb` exists (see [`playground.md`](./playground.md), the notebooks themselves generated by `scripts/generate-notebooks.mjs`).

There is no week-level `BonusContent`/unlock gating in the Astro build (the Docusaurus-era "pass the quiz to unlock bonus content" pattern was dropped along with the mode toggle) — all lessons and bonus-ish content are readable freely; gamification only awards XP/badges, it never gates access.
