# Learning Path Flow

Nobody lands inside a track blind. The click-path in the Astro build:

1. **Homepage** (`/` → `src/pages/index.astro`) — what the course is, the two sections (Python 101, Data Analysis), each with Normal and Hard tracks, plus a Projects teaser. Locale-detected; RTL for Arabic.
2. **Onboarding dialog** — shown once on first visit (gated on `pda:onboarded`), a non-blocking role=dialog in `Base.astro` (shared across all pages) with three "how this site works" steps (in `messages/*.json` where `.onboarding*` keys are UI-visible chrome, translated across all four locales) plus a Start CTA. It is **not** a learning-style picker: there is no Gamified/Classical `LearningStylePicker` and no `ModeToggle` in the Astro build (see [`gamification.md`](./gamification.md)) — the model is a single always-on gamified layer. Dismissal persists (`localStorage pda:onboarded`) so it doesn't flash on every visit; e2e covers focus-move, CTA, Escape, and remember-no-reappear.
3. **Learn hub** (`/learn`, `SharedLearnHub`/`LearnHub.astro`) — both track cards (🐍 Python 101, 📊 Data Analysis) with `m.track_1_name()`/`m.track_2_name()`/`m.track_1_desc()`/`m.track_2_desc()` messages, live lesson/module/minute counts and XP (rendered from the `lessons`/`modules` content collections), and per-locale `alternates` (`learn`, `ar/تعلم`, `es/aprender`, `fr/apprendre`).
4. **Track landing** (`/learn/<section>/<track>/index.astro`) — the section's lesson list grouped by module; both Normal and Hard share the same URL shape (`.../normal/`, `.../hard/`), trivially toggled. **There is no Hard gate and no placement quiz** in the Astro build — both Python 101 and Data Analysis open both tracks directly (the Docusaurus-era `PlacementQuiz` soft-gate was dropped).
5. **Lesson** (`.../lessons/[lesson].astro`, renders shared `LessonPage.astro`) — prose with inline runnable Pyodide cells, quizzes, and project/reasoning elements; progress (`pda:state`) and per-lesson `lessonRun`/`lessonComplete` XP are recorded as you go.
6. **Modules** (`.../modules/[module].astro`) — grouped module pages alongside lessons within a track.
7. **On every return visit**, `loadState()` stamps `lastActive` and bumps the daily streak via `bumpStreak()`/`awardDailyLogin()` in `gameState.ts` — the Duolingo-style nudge equivalent is the streak/XP surface itself (there is no `WelcomeBackBanner` in the Astro build). No push notifications, no backend.
