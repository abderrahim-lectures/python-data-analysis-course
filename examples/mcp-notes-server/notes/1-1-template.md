# 1:1 Meeting Template

date: 2026-04-01
tags: work, meetings, template

Reusable structure for weekly 1:1s -- copy this into a new dated note
rather than editing it in place.

## Agenda

1. **Wins since last time.** What went well, however small.
2. **Blockers.** What's stuck, and what would unstick it.
3. **Feedback, both directions.** Say the thing, don't save it for a
   performance review.
4. **One thing to try before next time.** Small and concrete beats
   ambitious and vague.

## Notes on running these well

Don't let status updates eat the whole slot -- those belong in async
written updates. Protect this time for the things that actually need two
people in a room (or a call) at once: judgment calls, friction, career
conversations.
