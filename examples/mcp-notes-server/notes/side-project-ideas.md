# Side Project Ideas

date: 2026-07-10
tags: projects, ideas, python

Running list, add as they come, prune quarterly.

- **Receipt OCR + spending tracker.** Photograph grocery receipts, extract
  line items with an OCR API, categorize spend automatically. Mostly
  useful as an excuse to learn a real OCR pipeline.
- **MCP server for these exact notes.** Expose this folder to Claude
  Desktop as searchable tools instead of grepping it by hand. (Building
  this one now -- see the course project.)
- **Static site build-time link checker.** A small script that crawls a
  built Docusaurus site and reports dead internal links before deploy,
  runnable as a CI step.
- **Personal weather-triggered todo.** "If it'll rain after 4pm, remind me
  to bring the laundry in" -- small, but genuinely useful daily.
- **Book note exporter.** Pull highlights out of an e-reader's export
  format and turn them into one Markdown note per book, matching the
  format of `atomic-habits.md` in this folder.
