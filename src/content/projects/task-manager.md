# Task Manager CLI

## What You'll Build

- A terminal-based task management system with Kanban boards
- Manage tasks with priorities, deadlines, and project grouping
- Track progress and visualize workflow from the terminal
- Never leave the terminal to manage your tasks

## Features

- **Kanban boards**: Visualize tasks in columns representing workflow stages
- **Priority levels**: Assign priority to tasks for better organization
- **Deadline tracking**: Set and monitor task deadlines
- **Project grouping**: Organize tasks by project for focused work
