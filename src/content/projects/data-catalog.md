# Data Catalog

## What You'll Build

- A searchable metadata catalog that indexes datasets, schemas, and data lineage
- Connect to databases, scan tables, and build a searchable catalog
- Track dataset ownership, types, and relationships across your organization
- Provide a single source of truth for data discovery

## Features

- **Auto-discovery**: Automatically scan and catalog datasets from multiple sources
- **Schema evolution tracking**: Monitor how schemas change over time
- **Data lineage**: Visualize how data flows between systems and transformations
- **Search**: Full-text search across datasets, columns, and metadata
