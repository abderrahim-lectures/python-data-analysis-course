# IoT Dashboard

See all your devices at a glance.

## What You'll Build

- A real-time device monitoring interface
- Live gauges and charts for sensor readings
- Geographic map view of device locations
- Device grouping and filtering capabilities

## Features

- **Real-time gauges** — Live updating dials and meters
- **Historical charts** — Time-series graphs for sensor trends
- **Map view** — Geographic visualization of device locations
- **Device grouping** — Organize devices by type, location, or function
