# LLM Prompt Optimizer

## What You'll Build

- A CLI tool that takes raw prompts and generates optimized variants
- Automatically try few-shot, chain-of-thought, and role-based patterns
- Compare prompt variants using built-in scoring metrics
- Export optimized prompts for downstream LLM workflows

## Features

- **Auto-Optimization** — Automatically generate and rank prompt variants
- **A/B Testing** — Compare prompts side by side on the same input
- **Few-Shot Injection** — Automatically select and insert relevant examples
- **Scoring Metrics** — Measure accuracy, consistency, and token efficiency
