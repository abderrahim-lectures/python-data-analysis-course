# Semantic Search Engine

## What You'll Build

- A vector-based search engine that understands natural language queries
- Index any document collection with embeddings for semantic similarity
- Provide faceted results with explanations of why each result matched
- Support hybrid search combining keyword and semantic approaches

## Features

- **Vector Search** — Search by meaning using dense embeddings
- **Hybrid Mode** — Combine keyword matching with semantic similarity for best results
- **Faceted Results** — Filter and explore results by category, date, or relevance
- **Explain Mode** — Understand why each result was returned and how it matches

## Stretch Goals

- [ ] Add support for image and PDF search alongside text
- [ ] Implement query expansion and suggestion features
- [ ] Build a REST API for integration with other applications
