# Biodiversity Logger

Contribute to citizen science.

## What You'll Build

- A wildlife observation recording interface
- Species database with identification helpers
- GPS-based location mapping for sightings
- Conservation status lookup and tracking

## Features

- **Species database** — Searchable catalog with taxonomy and images
- **Photo logging** — Attach photos to observation records
- **GPS mapping** — Plot sightings on interactive maps
- **Conservation status** — IUCN Red List integration for species risk

## Stretch Goals

- [ ] Add AI-powered species identification from photos
- [ ] Implement seasonal migration pattern detection
- [ ] Build community observation challenges and leaderboards
