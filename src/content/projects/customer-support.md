# Customer Support Dashboard

## What You'll Build
- A ticket management system with priority and status tracking
- An auto-routing engine for ticket assignment
- A canned response library for quick replies
- A satisfaction metrics dashboard with CSAT scoring

## Features
- **Auto-routing** — Assign tickets to agents based on skill and availability
- **SLA tracking** — Monitor response and resolution time commitments
- **Response templates** — Store and insert pre-written replies
- **CSAT metrics** — Track customer satisfaction scores over time

## Stretch Goals
- [ ] Add AI-powered ticket classification and suggested responses
- [ ] Build a knowledge base integration for self-service support
- [ ] Implement multi-channel support with unified inbox
