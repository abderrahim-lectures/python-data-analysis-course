# Geospatial Data Analyzer

## What You'll Build

- A tool that processes latitude and longitude data for geographic analysis
- Find patterns in geographic data through clustering and visualization
- Generate heatmaps and distance calculations
- Optimize routes between multiple points

## Features

- **Spatial clustering**: Group nearby points using DBSCAN and K-means
- **Heatmap generation**: Create heatmaps from geographic point data
- **Distance calculations**: Compute distances between coordinates using multiple formulas
- **Route optimization**: Find optimal routes through multiple waypoints

## Stretch Goals

- [ ] Add integration with OpenStreetMap and Google Maps APIs
- [ ] Build an interactive map visualization with Folium
- [ ] Implement geofencing and boundary detection
