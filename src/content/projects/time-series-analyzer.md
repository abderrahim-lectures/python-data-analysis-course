# Time Series Analyzer

## What You'll Build

- A tool that decomposes time series into trends, seasonality, and residuals
- Forecast future values using ARIMA and Prophet models
- Detect anomalies in temporal data automatically
- Analyze correlations between multiple time series

## Features

- **Auto-decomposition**: Automatically separate trends, seasonality, and residuals
- **ARIMA/Prophet forecasting**: Generate forecasts with configurable models
- **Correlation analysis**: Find relationships between different time series
- **Export**: Export analysis results to CSV, JSON, and visualization formats

## Stretch Goals

- [ ] Add a web dashboard for interactive time series exploration
- [ ] Implement real-time streaming anomaly detection
- [ ] Build a forecasting API for programmatic access
