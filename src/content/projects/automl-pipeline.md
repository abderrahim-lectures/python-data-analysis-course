# AutoML Pipeline

## What You'll Build

- Automatically preprocess data, select features, and choose models
- Tune hyperparameters using Bayesian optimization
- Compare 10+ algorithms and generate deployment-ready Python scripts
- Export trained models with preprocessing pipelines attached

## Features

- **Auto Preprocessing** — Handle missing values, encoding, and scaling automatically
- **Model Selection** — Compare algorithms like XGBoost, Random Forest, and neural networks
- **Bayesian Optimization** — Tune hyperparameters efficiently with intelligent search
- **Code Export** — Generate clean Python scripts ready for production deployment
