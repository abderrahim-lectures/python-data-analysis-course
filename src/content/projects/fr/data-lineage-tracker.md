# Suiveur de Lignée des Données

## Ce que vous construirez

- Un outil qui suit les transformations de bout en bout dans vos systèmes
- Visualiser comment les données circulent depuis les systèmes sources vers les tableaux de bord et rapports
- Comprendre d'où viennent les données et où elles vont après chaque transformation
- Réaliser des analyses d'impact lorsque les schémas sources changent

## Fonctionnalités

- **Graphes de lignée visuels**: Graphes interactifs montrant le flux de données entre les systèmes
- **Analyse d'impact**: Déterminer quels actifs downstream sont affectés par les changements
- **Suivi des changements**: Surveiller les changements de schéma et de données au fil du temps
- **Cartographie des dépendances**: Cartographier les dépendances entre tables, vues et pipelines
