# Catalogue de Données

## Ce que vous construirez

- Un catalogue de métadonnées consultable qui indexe les jeux de données, schémas et lignée de données
- Se connecter aux bases de données, scanner les tables et construire un catalogue consultable
- Suivre la propriété, les types et les relations des jeux de données dans votre organisation
- Fournir une source unique de vérité pour la découverte de données

## Fonctionnalités

- **Découverte automatique**: Scanner et indexer automatiquement les jeux de données depuis plusieurs sources
- **Suivi de l'évolution du schéma**: Surveiller comment les schémas changent au fil du temps
- **Lignée des données**: Visualiser comment les données circulent entre les systèmes et transformations
- **Recherche**: Recherche en texte complet dans les jeux de données, colonnes et métadonnées
