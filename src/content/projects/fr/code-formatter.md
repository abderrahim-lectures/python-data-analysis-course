# Formatteur de Code

## Ce que vous construirez

- Un formatteur qui lit le code Python et le reformate de manière cohérente
- Imposer un style cohérent dans toute votre équipe sans configuration
- Trier les imports, normaliser les chaînes et appliquer une indentation cohérente
- Générer des diffs montrant exactement ce qui a changé

## Fonctionnalités

- **Formatage sans configuration**: Fonctionne dès la sortie de la boîte avec des valeurs par défaut sensées
- **Tri des imports**: Organiser et trier automatiquement les statements d'import
- **Normalisation des chaînes**: Imposer des styles de guillemets cohérents et des séquences d'échappement
- **Sortie diff**: Montrer exactement quelles modifications ont été faites dans chaque fichier
