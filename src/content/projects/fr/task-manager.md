# Gestionnaire de Tâches CLI

## Ce que vous construirez

- Un système de gestion de tâches basé sur le terminal avec des tableaux Kanban
- Gérer les tâches avec des priorités, dates limites et regroupement par projet
- Suivre les progrès et visualiser le flux de travail depuis le terminal
- Ne plus jamais quitter le terminal pour gérer vos tâches

## Fonctionnalités

- **Tableaux Kanban**: Visualiser les tâches dans des colonnes représentant les étapes du flux de travail
- **Niveaux de priorité**: Attribuer des priorités aux tâches pour une meilleure organisation
- **Suivi des dates limites**: Définir et surveiller les dates limites des tâches
- **Regroupement par projet**: Organiser les tâches par projet pour un travail ciblé
