# Constructeur de Graphe de Connaissances

## Ce que vous allez construire

- Extrait des entités nommées comme personnes, organisations et lieux du texte
- Identifie les relations entre les entités et les stocke dans une base de données graphiques
- Visualisez les graphes de connaissances avec des outils d'exploration interactifs
- Interrogez les relations en utilisant un langage de requête graphique

## Fonctionnalités

- **Extraction NER** — Identifie les personnes, organisations, lieux et entités personnalisées
- **Détection de relations** — Découvre les relations entre les entités extraites
- **Visualisation de graphe** — Explorez les graphes de connaissances avec des diagrammes nœuds-liens interactifs
- **Langage de requête** — Écrivez des requêtes personnalisées pour parcourir et filtrer le graphe

## Objectifs supplémentaires

- [ ] Ajouter le support de l'import depuis des bases de données graphiques existantes
