# Générateur de Palette de Couleurs

## Ce que vous allez construire
- Un moteur de théorie des couleurs pour la génération de palettes harmonieuses
- Un vérificateur de contraste d'accessibilité pour la conformité WCAG
- Un système d'exportation pour plusieurs standards de format de couleur
- Un historique des palettes pour sauvegarder les combinaisons précédentes

## Fonctionnalités
- **Génération harmonieuse** — Créez des palettes complémentaires, analogues et triadiques
- **Vérification de contraste** — Validez les combinaisons de couleurs contre les directives WCAG
- **Formats d'exportation** — Sortez en CSS, configuration Tailwind, JSON ou variables SCSS
- **Historique des palettes** — Sauvegardez et revisitez les schémas de couleurs générés précédemment
