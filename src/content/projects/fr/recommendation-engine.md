# Moteur de Recommandations

## Ce que vous allez construire

- Collecte les interactions des utilisateurs et calcule les similarités entre éléments
- Sert les recommandations via une API REST propre
- Gère les scénarios de démarrage à froid pour les nouveaux utilisateurs et éléments
- Supporte les tests A/B pour mesurer la qualité des recommandations

## Fonctionnalités

- **Approche hybride** — Combine le filtrage collaboratif et basé sur le contenu
- **Gestion du démarrage à froid** — Fournit des recommandations significatives même avec peu de données
- **Mises à jour en temps réel** — Met à jour les recommandations au fur et à mesure des nouvelles interactions
- **Explicabilité** — Montre aux utilisateurs pourquoi chaque élément a été recommandé

## Objectifs supplémentaires

- [ ] Ajouter un tableau de bord web pour surveiller les performances des recommandations
- [ ] Implémenter des recommandations basées sur la session pour les visiteurs anonymes
- [ ] Créer un magasin de fonctionnalités pour gérer les attributs des éléments et utilisateurs
