# Hub de Capteurs IoT

Centre central pour tous vos capteurs.

## Ce que vous construirez

- Une passerelle de collecte de données multi-capteurs
- Un tableau de bord de surveillance en temps réel avec flux de capteurs en direct
- Un système d'alertes basé sur des seuils
- Le stockage et la récupération de données historiques

## Fonctionnalités

- **Agrégation de capteurs** — Collecter les données de température, humidité et mouvement
- **Tableaux de bord en temps réel** — Graphiques et jauges à mise à jour en direct
- **Alertes de seuil** — Notifications lorsque les lectures dépassent les plages sûres
- **Stockage de données** — Base de données de séries temporelles pour l'analyse historique

## Objectifs supplémentaires

- [ ] Ajouter le support du protocole MQTT pour la communication des capteurs
- [ ] Implémenter la détection d'anomalies sur les flux de capteurs
- [ ] Créer un système de plugins pour les types de capteurs personnalisés
