# Constructeur de Chatbots Sans Code

## Ce que vous allez construire

- Un éditeur visuel de flux pour concevoir la logique de conversation
- Déployez des chatbots sur Slack, WhatsApp ou le web en un clic
- Gère la classification d'intentions et l'extraction d'entités automatiquement
- Maintient le contexte de conversation à travers les interactions multi-tours

## Fonctionnalités

- **Éditeur visuel** — Concevez des flux de conversation avec une interface glisser-déposer
- **Moteur NLU** — Classification d'intentions et extraction d'entités intégrées
- **Gestion du contexte** — Maintient l'état de conversation entre plusieurs tours
- **Déploiement multi-canal** — Publiez sur Slack, WhatsApp, le web et plus

## Objectifs supplémentaires

- [ ] Ajouter un tableau de bord analytique montrant les métriques de conversation
- [ ] Implémenter le transfert à un humain pour les conversations complexes
- [ ] Supporter les données d'entraînement personnalisées pour les intentions spécifiques au domaine
