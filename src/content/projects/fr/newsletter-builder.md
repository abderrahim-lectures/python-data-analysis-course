# Constructeur de Newsletters

## Ce que vous allez construire
- Une plateforme de création de newsletters utilisant des modèles Markdown
- Un système de gestion des abonnés avec segmentation de listes
- Un moteur de livraison d'email avec suivi d'ouvertures
- Un cadre de test A/B pour l'optimisation des objets

## Fonctionnalités
- **Modèles Markdown** — Écrivez des newsletters en Markdown avec aperçu HTML
- **Listes d'abonnés** — Gérez les contacts avec tags et segmentation
- **Suivi d'ouvertures** — Surveillez les ouvertures d'email et les clics
- **Objets A/B** — Testez différents objets pour un meilleur engagement

## Objectifs supplémentaires
- [ ] Ajouter l'automatisation de campagnes drip pour l'onboarding des abonnés
- [ ] Construire un éditeur visuel par glisser-déposer en complément du Markdown
- [ ] Implémenter l'intégration avec les fournisseurs de services email populaires
