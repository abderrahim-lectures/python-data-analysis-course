# Nettoyeur de Données IA

## Ce que vous allez construire

- Profile les jeux de données et identifie les problèmes de qualité automatiquement
- Suggère et applique des corrections pour les valeurs manquantes, outliers et doublons
- Valide les données nettoyées par rapport aux schémas et règles métier
- Maintient un registre complet de toutes les transformations appliquées

## Fonctionnalités

- **Détection automatique** — Identifie les valeurs manquantes, outliers, doublons et erreurs de format
- **Imputation intelligente** — Remplit les valeurs manquantes en utilisant des méthodes statistiques et ML
- **Normalisation du format** — Standardise les dates, devises et formats de texte
- **Registre d'audit** — Suit chaque changement effectué sur le jeu de données original

## Objectifs supplémentaires

- [ ] Ajouter une interface web pour réviser et approuver les corrections suggérées
- [ ] Implémenter un système de règles personnalisées pour la validation spécifique au domaine
- [ ] Créer une intégration avec les bases de données et entrepôts de données populaires
