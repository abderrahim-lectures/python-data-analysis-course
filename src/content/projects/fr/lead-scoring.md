# Moteur de Scoring de Leads

## Ce que vous allez construire
- Un modèle de scoring de leads utilisant les données d'engagement et démographiques
- Un système de priorisation de pipeline pour les équipes commerciales
- Un cadre de test A/B pour la comparaison de modèles de scoring
- Une couche d'intégration CRM pour les mises à jour de leads en temps réel

## Fonctionnalités
- **Scoring multifactor** — Combinez les signaux d'engagement, démographie et comportement
- **Intégration CRM** — Synchronisez les scores avec votre système CRM existant
- **Test A/B** — Comparez différents modèles de scoring et seuils
- **Analytiques de pipeline** — Visualisez le flux de leads et les taux de conversion

## Objectifs supplémentaires
- [ ] Ajouter l'entraînement de modèles de machine learning pour le scoring personnalisé
- [ ] Construire un pipeline d'enrichissement de leads avec des sources de données externes
- [ ] Implémenter l'attribution automatique de leads basée sur des seuils de scoring
