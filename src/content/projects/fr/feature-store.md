# Magasin de Features

## Ce que vous construirez

- Un référentiel centralisé de features pour les modèles de machine learning
- Calculer les features une fois et les servir pour l'entraînement et l'inférence
- Versionner les features et les partager entre équipes et projets
- Fournir un service online et offline avec correction dans le temps

## Fonctionnalités

- **Versionnage des features**: Suivre et gérer les versions des features au fil du temps
- **Service online/offline**: Servir les features pour l'inférence en temps réel et l'entraînement par lots
- **Correction dans le temps**: Assurer la cohérence des features pour les données d'entraînement
- **Partage**: Partager les features calculées entre équipes et projets

- [ ] Ajouter une UI de découverte de features avec recherche et documentation
- [ ] Implémenter la surveillance des features et le suivi de fraîcheur
- [ ] Construire une intégration avec les frameworks ML populaires (scikit-learn, PyTorch)
