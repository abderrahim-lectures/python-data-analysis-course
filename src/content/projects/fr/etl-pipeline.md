# Constructeur de Pipeline ETL

## Ce que vous allez construire

- Extrayez des données depuis des APIs, bases de données et systèmes de fichiers automatiquement
- Appliquez des transformations incluant le nettoyage, l'agrégation et l'enrichissement
- Chargez les données traitées dans les bases de données cibles ou entrepôts de données
- Planifiez les pipelines avec cron et gérez les échecs avec grâce

## Fonctionnalités

- **Extraction multi-source** — Tirez des données des REST APIs, bases de données SQL et fichiers
- **Transformation de données** — Nettoyez, agréguez et enrichissez les données dans les étapes du pipeline
- **Chargement incrémental** — Traitez uniquement les enregistrements nouveaux ou modifiés pour l'efficacité
- **Logique de réessai** — Gérez les échecs transitoires avec réessai automatique et backoff

## Objectifs supplémentaires

- [ ] Ajouter un tableau de bord web pour surveiller la santé du pipeline
- [ ] Implémenter des vérifications de qualité des données entre les étapes du pipeline
- [ ] Créer un marché de connecteurs pour les sources contribuées par la communauté
