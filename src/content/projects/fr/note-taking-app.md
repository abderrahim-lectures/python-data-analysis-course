# App de Prise de Notes en Markdown

## Ce que vous construirez

- Une application basée sur le terminal pour stocker et organiser des notes en Markdown
- Rechercher dans toutes les notes avec la recherche en texte complet
- Organiser les notes avec des tags et catégories
- Exporter les notes en PDF pour le partage

## Fonctionnalités

- **Recherche en texte complet**: Rechercher dans toutes les notes instantanément
- **Système de tags**: Organiser les notes avec des tags flexibles
- **Aperçu Markdown**: Rendre le Markdown avec coloration syntaxique dans le terminal
- **Export PDF**: Générer des documents PDF à partir de notes Markdown
