# Gradebook

Simplify grade management.

## What You'll Build

- A grade entry system with weighted category support
- Automatic GPA calculation across semesters
- Report card generation with customizable templates
- Parent portal for viewing student progress

## Features

- **Weighted grading** — Configure assignment categories with weights
- **GPA calculation** — Automatic cumulative and semester GPA
- **Report cards** — PDF generation with letter grades and comments
- **Parent access** — Secure portal for guardians to view progress
