# Voice Cloning Toolkit

## What You'll Build

- Take 5–30 seconds of reference audio and generate new speech in that voice
- Train speaker embeddings for consistent voice reproduction
- Generate synthetic speech with controllable style and pacing
- Support multiple languages for cross-lingual voice cloning

## Features

- **Few-Shot Cloning** — Clone a voice from just a handful of audio samples
- **Style Transfer** — Apply emotional and speaking style variations to cloned voices
- **Real-Time Streaming** — Generate speech in real time for live applications
- **Multi-Language** — Support English, Spanish, French, and more

## Stretch Goals

- [ ] Add a web interface for recording and previewing cloned voices
- [ ] Implement voice conversion between two speakers
- [ ] Build a REST API for on-demand voice synthesis
