# AI Music Composer

## What You'll Build

- Generate MIDI melodies from style or seed inputs
- Apply musical style transfer between different genres
- Create harmony accompaniment for existing melodies
- Export compositions as MIDI files for use in any DAW

## Features

- **Style Transfer** — Generate music in the style of different genres and artists
- **Melody Generation** — Create original melodies from seed notes or moods
- **Harmony Accompaniment** — Add chord progressions and backing tracks
- **MIDI Export** — Save compositions as standard MIDI files

- [ ] Add a web interface with a visual piano roll editor
