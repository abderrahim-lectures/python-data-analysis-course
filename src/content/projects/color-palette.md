# Color Palette Generator

## What You'll Build
- A color theory engine for harmonious palette generation
- An accessibility contrast checker for WCAG compliance
- An export system for multiple color format standards
- A palette history tracker for saved combinations

## Features
- **Harmonious generation** — Create complementary, analogous, and triadic palettes
- **Contrast checking** — Validate color combinations against WCAG guidelines
- **Export formats** — Output as CSS, Tailwind config, JSON, or SCSS variables
- **Palette history** — Save and revisit previously generated color schemes
