# AI Test Generator

## What You'll Build

- Read source code and generate comprehensive test suites automatically
- Detect edge cases and boundary conditions that developers often miss
- Create property-based tests for mathematical and data transformation functions
- Analyze coverage and suggest additional tests for untested paths

## Features

- **Unit Test Generation** — Create pytest and unittest code from function signatures
- **Edge Case Detection** — Identify boundary conditions and error paths
- **Property-Based Tests** — Generate hypothesis-based tests for data functions
- **Coverage Analysis** — Find untested code paths and suggest new tests

## Stretch Goals

- [ ] Add integration with CI/CD for automatic test creation on PRs
- [ ] Support mutation testing to validate test effectiveness
- [ ] Build a test review interface for approving generated tests
