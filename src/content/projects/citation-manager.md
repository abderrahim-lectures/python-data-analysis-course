# Citation Manager

## What You'll Build
- A bibliography manager that stores and organizes references
- An automatic formatter supporting APA, MLA, Chicago, and BibTeX styles
- A DOI import system for quick reference collection
- A browser extension for capturing citations from web pages

## Features
- **Multiple format styles** — Switch between APA, MLA, Chicago, and BibTeX instantly
- **Import from DOI** — Add references by entering a DOI or URL
- **Browser extension** — Capture citations directly from academic websites
- **Word integration** — Insert formatted citations into documents

- [ ] Build a collaboration feature for shared research bibliographies
