# Secret Manager

## What You'll Build

- A tool that encrypts secrets at rest using AES-256 encryption
- Rotate API keys and passwords automatically on schedule
- Maintain a complete audit trail of all secret access
- Share secrets securely within teams with access controls

## Features

- **AES-256 encryption**: Encrypt all secrets with military-grade encryption
- **Automatic rotation**: Rotate secrets on configurable schedules
- **Audit trail**: Track every access and modification to secrets
- **Team sharing**: Share secrets securely with role-based access controls

- [ ] Add integration with cloud KMS (AWS KMS, GCP KMS)
- [ ] Build a web dashboard for secret management
