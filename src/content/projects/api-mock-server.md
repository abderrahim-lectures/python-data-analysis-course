# API Mock Server

## What You'll Build

- A mock server that reads OpenAPI and Swagger specs to generate realistic APIs
- Provide realistic data generation based on schema definitions
- Simulate network latency and error scenarios for testing
- Record and replay real API interactions for offline development

## Features

- **Realistic data generation**: Generate mock data that matches schema types and constraints
- **Latency simulation**: Add configurable delays to simulate real network conditions
- **Scenario recording**: Record real API interactions and replay them as mocks
- **Proxy mode**: Forward requests to a real backend while logging responses

- [ ] Add a web dashboard for managing mock endpoints and data
- [ ] Implement contract testing between frontend and mock server
- [ ] Build a shared mock server for team collaboration
