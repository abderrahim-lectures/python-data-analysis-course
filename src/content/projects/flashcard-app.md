# Flashcard App

Learn faster with scientifically optimized review.

## What You'll Build

- A flashcard deck manager with categories and tags
- Spaced repetition scheduling using the SM-2 algorithm
- Progress tracking with retention statistics
- Import and export decks from popular formats

## Features

- **Spaced repetition** — SM-2 algorithm optimizes review intervals
- **Deck management** — Create, organize, and share flashcard decks
- **Progress tracking** — Track mastery levels and retention rates
- **Import/export** — Support for Anki and CSV format exchange
