# Code Formatter

## What You'll Build

- An opinionated formatter that reads Python source and reformats it consistently
- Enforce consistent style across your entire team with zero configuration
- Sort imports, normalize strings, and apply consistent indentation
- Generate diffs showing exactly what changed

## Features

- **Zero-config formatting**: Works out of the box with sensible defaults
- **Import sorting**: Automatically organize and sort import statements
- **String normalization**: Enforce consistent quote styles and escape sequences
- **Diff output**: Show exactly what changes were made in each file
