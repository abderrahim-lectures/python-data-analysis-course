# AI Tutor Assistant

## What You'll Build

- A learning companion that adapts explanations based on your responses
- Use Socratic questioning to deepen understanding
- Track learning progress and identify knowledge gaps
- Cover multiple topics from programming to science

## Features

- **Adaptive Difficulty** — Adjust explanation complexity based on learner performance
- **Socratic Questioning** — Guide discovery through thoughtful follow-up questions
- **Progress Tracking** — Monitor understanding and recommend next topics
- **Multi-Topic Support** — Cover programming, math, science, and more

- [ ] Add spaced repetition for reinforcing learned concepts
- [ ] Implement voice-based interaction for hands-free learning
