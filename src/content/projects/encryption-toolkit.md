# Encryption Toolkit

Protect your data with encryption.

## What You'll Build

- AES-256 file and text encryption/decryption
- RSA key pair generation and management
- Secure key exchange protocol implementation
- Encrypted messaging with end-to-end protection

## Features

- **AES-256 encryption** — Industry-standard symmetric encryption for files
- **RSA key exchange** — Asymmetric encryption for secure key sharing
- **File encryption** — Encrypt and decrypt files with passphrase protection
- **Secure messaging** — End-to-end encrypted message exchange
