# Email Campaign Manager

## What You'll Build

- A system for building and managing email campaigns
- Create reusable email templates with variable substitution
- Track open rates and click-through rates for campaign analytics
- Run A/B tests to optimize email content and subject lines

## Features

- **Template engine**: Build reusable email templates with Jinja2 or similar
- **Open/click tracking**: Monitor engagement with pixel tracking and link wrapping
- **A/B testing**: Test different subject lines, content, and send times
- **Subscriber management**: Manage subscriber lists with segmentation

## Stretch Goals

- [ ] Add support for transactional email workflows
- [ ] Build a web dashboard for campaign analytics
- [ ] Implement automated drip campaigns based on triggers
