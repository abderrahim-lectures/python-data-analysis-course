# Document Q&A Engine

## What You'll Build

- A RAG pipeline that ingests PDFs, DOCX files, and spreadsheets
- Answer natural language questions with accurate, cited responses
- Provide source citations so you can verify each answer
- Support conversational follow-up questions in chat mode

## Features

- **Multi-Format Ingestion** — Process PDFs, Word documents, Excel files, and plain text
- **Source Citations** — Every answer links back to the exact source location
- **Context Window** — Maintain conversation context across multiple questions
- **Chat Mode** — Ask follow-up questions without re-uploading documents

- [ ] Add support for scanned documents with OCR
