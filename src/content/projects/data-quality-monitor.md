# Data Quality Monitor

## What You'll Build

- A system that runs continuous data quality checks on data in motion and at rest
- Define quality rules and monitor schema changes over time
- Detect anomalies and data drift across your pipelines
- Generate quality scores and send alerts when thresholds are breached

## Features

- **Quality scoring**: Assign quality scores to datasets based on configurable rules
- **Drift detection**: Detect statistical drift in data distributions
- **Alerting**: Send notifications when quality checks fail
- **Historical comparison**: Compare current data against historical baselines

## Stretch Goals

- [ ] Add a web dashboard for quality metrics visualization
- [ ] Integrate with Airflow or Dagster for pipeline-aware checks
- [ ] Build a recommendation engine for quality rule suggestions
