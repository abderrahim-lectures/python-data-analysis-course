# Wiki Engine

## What You'll Build

- A lightweight wiki system built on Markdown pages
- Track version history for every page with full diff support
- Search across all pages and navigate with backlinks
- Enable collaborative editing for team documentation

## Features

- **Page versioning**: Track every change with full version history
- **Backlinks**: Navigate between related pages automatically
- **Search**: Full-text search across all wiki pages
- **Collaborative editing**: Multiple users can edit pages simultaneously

- [ ] Add real-time collaborative editing with operational transform
