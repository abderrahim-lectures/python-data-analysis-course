# No-Code Chatbot Builder

## What You'll Build

- A visual flow editor for designing conversation logic
- Deploy chatbots to Slack, WhatsApp, or web with one click
- Handle intent classification and entity extraction automatically
- Manage conversation context across multi-turn interactions

## Features

- **Visual Editor** — Design conversation flows with a drag-and-drop interface
- **NLU Engine** — Built-in intent classification and entity extraction
- **Context Management** — Maintain conversation state across multiple turns
- **Multi-Channel Deploy** — Publish to Slack, WhatsApp, web, and more

## Stretch Goals

- [ ] Add analytics dashboard showing conversation metrics
- [ ] Implement human handoff for complex conversations
- [ ] Support custom training data for domain-specific intents
