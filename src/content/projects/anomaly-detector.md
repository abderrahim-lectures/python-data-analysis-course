# Anomaly Detection System

## What You'll Build

- A pipeline ingesting time-series data and applying multiple detection methods
- Classify anomalies by type and severity with automatic alerting
- Adapt baselines automatically to account for seasonality and trends
- Provide root cause suggestions for detected anomalies

## Features

- **Multiple Methods** — Use Z-score, Isolation Forest, and DBSCAN for detection
- **Auto-Baseline** — Automatically establish and update normal behavior baselines
- **Seasonality Handling** — Account for daily, weekly, and seasonal patterns
- **Root Cause Suggestions** — Correlate anomalies with recent changes and events

## Stretch Goals

- [ ] Add a real-time dashboard with live anomaly visualization
- [ ] Implement predictive alerting before anomalies occur
- [ ] Build integration with PagerDuty and Opsgenie for incident management
