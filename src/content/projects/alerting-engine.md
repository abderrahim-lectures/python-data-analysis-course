# Alerting Engine

Never miss a critical alert.

## What You'll Build

- A multi-channel notification delivery system
- Escalation policy configuration and management
- Alert deduplication and grouping logic
- On-call rotation scheduling and routing

## Features

- **Multi-channel delivery** — Send alerts via email, SMS, Slack, and webhook
- **Escalation chains** — Automatically escalate unacknowledged alerts
- **Deduplication** — Group similar alerts to reduce noise
- **On-call rotation** — Schedule and manage on-call rotations
