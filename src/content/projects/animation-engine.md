# Animation Engine

## What You'll Build
- An animation framework with easing function support
- A timeline controller for sequencing multiple animations
- A keyframe interpolation engine for smooth transitions
- An SVG animation renderer for vector-based graphics

## Features
- **Easing functions** — Apply ease-in, ease-out, bounce, and custom curves
- **Timeline control** — Sequence animations with delays and parallel tracks
- **Keyframe interpolation** — Define start and end states for smooth transitions
- **SVG animations** — Animate vector paths, shapes, and transformations

## Stretch Goals
- [ ] Add a visual timeline editor with drag-and-drop
- [ ] Build a physics-based animation system with spring dynamics
- [ ] Implement scroll-triggered animation sequences
