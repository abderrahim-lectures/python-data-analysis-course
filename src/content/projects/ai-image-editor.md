# AI Image Editor

## What You'll Build

- Accept images and text instructions to perform edits automatically
- Remove objects, change backgrounds, and apply artistic styles
- Process batches of images with consistent editing rules
- Use diffusion models for high-quality image manipulation

## Features

- **Text Commands** — Describe edits in natural language and get results
- **Inpainting** — Remove objects and fill in missing areas seamlessly
- **Style Transfer** — Apply artistic styles from reference images
- **Batch Editing** — Process entire directories with consistent rules

## Stretch Goals

- [ ] Add a web interface with before/after previews
- [ ] Implement history and undo for non-destructive editing
- [ ] Build a plugin system for custom editing operations
