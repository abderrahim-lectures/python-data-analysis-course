# Real-Time Chat App

## What You'll Build

- A WebSocket server with real-time bidirectional communication
- Support multiple chat rooms with independent message streams
- Show typing indicators when users are composing messages
- Store and retrieve message history for each room

## Features

- **Multiple Rooms** — Create and manage separate chat spaces
- **Typing Indicators** — See when other users are typing in real time
- **Message History** — Scroll back through past conversations
- **Emoji Reactions** — React to messages with custom emoji responses

## Stretch Goals

- [ ] Add end-to-end encryption for private conversations
- [ ] Implement file and image sharing within rooms
- [ ] Build presence indicators showing online users
