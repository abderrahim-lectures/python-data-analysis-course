# Image Caption Generator

## What You'll Build

- Accept image uploads or URLs and generate human-readable captions
- Use pre-trained vision-language models like BLIP or LLaVA
- Provide confidence scores alongside each generated caption
- Support batch processing of entire image directories

## Features

- **Multiple Models** — Switch between BLIP, LLaVA, and other vision-language models
- **Batch Mode** — Process hundreds of images in one run with progress tracking
- **Custom Vocab** — Add domain-specific terms to improve caption accuracy
- **EXIF Export** — Embed generated captions into image metadata automatically

- [ ] Add a web UI with drag-and-drop upload
