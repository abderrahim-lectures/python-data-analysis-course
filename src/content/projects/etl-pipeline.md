# ETL Pipeline Builder

## What You'll Build

- Extract data from APIs, databases, and file systems automatically
- Apply transformations including cleaning, aggregation, and enrichment
- Load processed data into target databases or data warehouses
- Schedule pipelines with cron and handle failures gracefully

## Features

- **Multi-Source Extraction** — Pull data from REST APIs, SQL databases, and files
- **Data Transformation** — Clean, aggregate, and enrich data in pipeline stages
- **Incremental Loading** — Process only new or changed records for efficiency
- **Retry Logic** — Handle transient failures with automatic retry and backoff
