# Sentiment Analysis Dashboard

## What You'll Build

- A live dashboard monitoring social media sentiment in real time
- Stream text from APIs, run NLP analysis, store in a time-series database
- Display trend charts with keyword-based alert triggers
- Track sentiment shifts across multiple platforms simultaneously

## Features

- **Real-time Streaming** — Ingest and analyze social media feeds as they arrive
- **Multi-Model Comparison** — Compare VADER, TextBlob, and transformer-based sentiment models side by side
- **Keyword Alerts** — Set up triggers that notify you when specific topics spike or drop
- **Historical Trends** — Visualize sentiment over time with interactive charts and export options

## Stretch Goals

- [ ] Add WebSocket-based live updates to the dashboard
- [ ] Implement multi-language sentiment detection
- [ ] Build a Slack or Discord bot that posts alerts on threshold breaches
