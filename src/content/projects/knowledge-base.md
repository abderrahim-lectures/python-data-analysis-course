# Personal Knowledge Base

## What You'll Build

- A linked note system inspired by the Zettelkasten method
- Connect ideas with bidirectional links and backlinks
- Visualize your knowledge as an interactive graph
- Search across all notes with full-text search

## Features

- **Bidirectional links**: Link notes together and see connections automatically
- **Knowledge graph viz**: Explore your knowledge as an interactive graph
- **Full-text search**: Search across all notes instantly
- **Tag system**: Organize notes with flexible tagging and categories

## Stretch Goals

- [ ] Add AI-powered note suggestions based on content similarity
- [ ] Implement note templates for different types of knowledge
- [ ] Build a spaced repetition system for review
