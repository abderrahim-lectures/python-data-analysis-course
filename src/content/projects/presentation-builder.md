# Presentation Builder

## What You'll Build

- A tool that converts Markdown into beautiful slide decks
- Apply themes and transitions for professional presentations
- Add speaker notes for presentation guidance
- Export slides to PDF for sharing

## Features

- **Theme system**: Choose from built-in themes or create custom ones
- **Transitions**: Add animated transitions between slides
- **Speaker notes**: Include notes visible only to the presenter
- **PDF export**: Generate PDF versions of slide decks

- [ ] Add support for embedded images and videos
