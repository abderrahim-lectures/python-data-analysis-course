# LLM Evaluation Suite

## What You'll Build

- Standardized test suites for comparing multiple LLMs
- Measure accuracy, latency, and hallucination rates across models
- Track costs and generate performance reports
- Run safety checks to detect bias and harmful outputs

## Features

- **Multi-Model Testing** — Compare GPT, Claude, Llama, and other models side by side
- **Custom Tests** — Create your own evaluation benchmarks and test cases
- **Cost Tracking** — Monitor token usage and compute costs per model
- **Safety Checks** — Detect bias, toxicity, and hallucination in outputs
