# Podcast Analyzer

## What You'll Build
- A transcription pipeline for podcast audio files
- A summarization engine for episode content
- A topic detection system for content organization
- A guest extraction tool for speaker identification

## Features
- **Transcription** — Convert spoken audio to accurate text transcripts
- **Summarization** — Generate concise episode summaries and key takeaways
- **Topic detection** — Identify main themes and discussion topics
- **Guest extraction** — Identify and list episode participants

## Stretch Goals
- [ ] Add sentiment analysis for guest and host tone tracking
- [ ] Build a podcast RSS feed parser for batch processing
- [ ] Implement cross-episode topic trending and evolution tracking
