# Data Lineage Tracker

## What You'll Build

- A tool that tracks data transformations end-to-end across your systems
- Visualize how data flows from source systems to dashboards and reports
- Understand where data comes from and where it goes after each transformation
- Perform impact analysis when source schemas change

## Features

- **Visual lineage graphs**: Interactive graphs showing data flow between systems
- **Impact analysis**: Determine which downstream assets are affected by changes
- **Change tracking**: Monitor schema and data changes over time
- **Dependency mapping**: Map dependencies between tables, views, and pipelines

## Stretch Goals

- [ ] Add support for dbt, Airflow, and Spark lineage extraction
- [ ] Build an API for programmatic lineage queries
- [ ] Implement automated impact reports on schema changes
