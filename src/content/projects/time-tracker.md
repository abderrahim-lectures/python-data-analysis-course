# Time Tracker

## What You'll Build

- A tool that tracks time spent on tasks with start and stop timers
- Generate daily and weekly time reports
- Create invoices from tracked time entries
- Visualize productivity with charts and analytics

## Features

- **Timer tracking**: Start and stop timers for individual tasks
- **Daily/weekly reports**: Generate summary reports of time spent
- **Invoice generation**: Create invoices from time entries with customizable templates
- **Productivity charts**: Visualize where your time goes with interactive charts

- [ ] Add integration with Toggl and Harvest APIs
