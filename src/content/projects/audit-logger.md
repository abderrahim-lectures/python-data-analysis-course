# Audit Logger

Keep a tamper-proof record of everything.

## What You'll Build

- An append-only audit log with cryptographic integrity
- Tamper detection using hash chains and signatures
- Compliance report generation for regulatory requirements
- Configurable retention policies with automated cleanup

## Features

- **Tamper detection** — Hash chain verification for log integrity
- **Compliance reports** — Generate SOC 2 and GDPR compliance exports
- **Retention policies** — Automated log rotation and archival
- **Search** — Full-text search across audit events with filters

- [ ] Add real-time log streaming to SIEM systems
