# AI Code Review Bot

## What You'll Build

- Watch GitHub pull requests and analyze code changes with an LLM
- Post review comments directly on diffs with actionable suggestions
- Enforce coding style guidelines and detect common bug patterns
- Track code quality metrics across your project over time

## Features

- **Diff Analysis** — Understand the context of changes and review meaningfully
- **Bug Detection** — Catch common pitfalls like null references and race conditions
- **Style Enforcement** — Apply and enforce custom coding standards automatically
- **Security Scan** — Flag potential vulnerabilities in new code
