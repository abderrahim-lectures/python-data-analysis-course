# Document Converter

## What You'll Build

- A universal document format converter supporting Markdown, HTML, PDF, DOCX, and LaTeX
- Apply custom style templates to maintain consistent formatting
- Convert documents in batch for large-scale processing
- Inherit and compose styles across document types

## Features

- **Multi-format support**: Convert between Markdown, HTML, PDF, DOCX, and LaTeX
- **Custom templates**: Apply custom styles and themes to converted documents
- **Batch conversion**: Process multiple documents at once
- **Style inheritance**: Compose and reuse styles across document types
