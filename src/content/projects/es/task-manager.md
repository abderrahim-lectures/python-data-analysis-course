# Gestor de Tareas CLI

## Lo que construirás

- Un sistema de gestión de tareas basado en terminal con tableros Kanban
- Gestionar tareas con prioridades, fechas límite y agrupación por proyecto
- Rastrear progreso y visualizar el flujo de trabajo desde la terminal
- Nunca salir de la terminal para gestionar tus tareas

## Características

- **Tableros Kanban**: Visualizar tareas en columnas que representan etapas del flujo de trabajo
- **Niveles de prioridad**: Asignar prioridad a tareas para mejor organización
- **Seguimiento de fechas límite**: Establecer y monitorear fechas límite de tareas
- **Agrupación por proyecto**: Organizar tareas por proyecto para trabajo enfocado
