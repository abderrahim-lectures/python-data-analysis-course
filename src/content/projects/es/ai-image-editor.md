# Editor de Imágenes con IA

## Lo que construirás

- Acepta imágenes e instrucciones de texto para realizar ediciones automáticamente
- Elimina objetos, cambia fondos y aplica estilos artísticos
- Procesa lotes de imágenes con reglas de edición consistentes
- Usa modelos de difusión para manipulación de imágenes de alta calidad

## Características

- **Comandos de texto** — Describe ediciones en lenguaje natural y obtén resultados
- **Inpainting** — Elimina objetos y llena áreas faltantes sin costuras
- **Transferencia de estilo** — Aplica estilos artísticos de imágenes de referencia
- **Edición por lotes** — Procesa directorios completos con reglas consistentes
