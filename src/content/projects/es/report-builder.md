# Constructor de Informes

## Lo que construirás
- Un pipeline de datos a informes con generación basada en plantillas
- Una biblioteca de gráficos y visualización para métricas empresariales
- Un sistema de exportación a PDF para salida de informes pulida
- Un motor de programación para entrega automatizada de informes

## Características
- **Generación de gráficos** — Crea gráficos de barras, líneas, circular y dispersión a partir de datos
- **Formato de tablas** — Construye tablas estructuradas con ordenamiento y filtrado
- **Exportar a PDF** — Genera documentos de informes profesionales
- **Generación programada** — Automatiza la entrega de informes semanales y mensuales
