# Cuaderno de Laboratorio Digital

## Lo que construirás
- Un cuaderno digital para registrar experimentos científicos con plantillas estructuradas
- Un motor de cálculo integrado para análisis de datos
- Un sistema de historial de versiones para rastrear iteraciones de experimentos
- Un pipeline de exportación a PDF para compartir resultados reproducibles

## Características
- **Plantillas de experimentos** — Estructuras predefinidas para flujos de trabajo comunes
- **Cálculos integrados** — Ejecuta análisis estadísticos y fórmulas directamente en las entradas
- **Historial de versiones** — Rastrea cada cambio con vista de diferencias y reversión
- **Exportar a PDF** — Genera informes de experimentos listos para publicación
