# Motor de Animación

## Lo que construirás
- Un framework de animaciones con soporte de funciones de easing
- Un controlador de línea de tiempo para secuenciar múltiples animaciones
- Un motor de interpolación de keyframes para transiciones suaves
- Un renderizador de animaciones SVG para gráficos vectoriales

## Características
- **Funciones de easing** — Aplica ease-in, ease-out, rebote y curvas personalizadas
- **Control de línea de tiempo** — Secuencia animaciones con retrasos y pistas paralelas
- **Interpolación de keyframes** — Define estados inicial y final para transiciones suaves
- **Animaciones SVG** — Anima rutas vectoriales, formas y transformaciones
