# Monitor de Calidad de Datos

## Lo que construirás

- Un sistema que ejecuta verificaciones continuas de calidad de datos en movimiento y en reposo
- Definir reglas de calidad y monitorear cambios de esquema con el tiempo
- Detectar anomalías y deriva de datos en tus pipelines
- Generar puntuaciones de calidad y enviar alertas cuando se superen umbrales

## Características

- **Puntuación de calidad**: Asignar puntuaciones de calidad a conjuntos de datos basadas en reglas configurables
- **Detección de deriva**: Detectar deriva estadística en distribuciones de datos
- **Alertas**: Enviar notificaciones cuando fallen las verificaciones de calidad
- **Comparación histórica**: Comparar datos actuales contra baselines históricos

## Objetivos adicionales

- [ ] Agregar un dashboard web para visualización de métricas de calidad
- [ ] Integrar con Airflow o Dagster para verificaciones awareness del pipeline
- [ ] Construir un motor de recomendaciones para sugerencias de reglas de calidad
