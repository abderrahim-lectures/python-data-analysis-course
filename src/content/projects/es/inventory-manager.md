# Gestor de Inventario

## Lo que construirás
- Un sistema de seguimiento de stock en múltiples almacenes
- Una interfaz de escaneo de códigos de barras para actualizaciones rápidas de inventario
- Un sistema de alertas para stock bajo y activadores de reorden
- Un sistema de seguimiento de transferencias entre ubicaciones de almacén

## Características
- **Escaneo de códigos de barras** — Escanea artículos para actualizaciones y búsquedas rápidas
- **Alertas de stock** — Establece niveles mínimos y recibe notificaciones de reorden
- **Transferencias de almacén** — Rastrea artículos que se mueven entre ubicaciones
- **Pronóstico de ventas** — Predice necesidades futuras de stock con datos históricos
