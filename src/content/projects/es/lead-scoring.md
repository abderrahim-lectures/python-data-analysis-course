# Motor de Puntuación de Leads

## Lo que construirás
- Un modelo de puntuación de leads usando datos de participación y demografía
- Un sistema de priorización de pipeline para equipos de ventas
- Un marco de prueba A/B para comparación de modelos de puntuación
- Una capa de integración CRM para actualizaciones de leads en tiempo real

## Características
- **Puntuación multifactor** — Combina señales de participación, demografía y comportamiento
- **Integración CRM** — Sincroniza puntuaciones con tu sistema CRM existente
- **Prueba A/B** — Compara diferentes modelos de puntuación y umbrales
- **Analíticas de pipeline** — Visualiza flujo de leads y tasas de conversión

- [ ] Construir un pipeline de enriquecimiento de leads con fuentes de datos externas
