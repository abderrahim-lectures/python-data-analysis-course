# Rastreador de Tiempo

## Lo que construirás

- Una herramienta que rastrea tiempo dedicado a tareas con temporizadores de inicio y parada
- Generar reportes diarios y semanales de tiempo
- Crear facturas desde entradas de tiempo rastreadas
- Visualizar productividad con gráficos y analíticas

## Características

- **Rastreo de temporizador**: Iniciar y detener temporizadores para tareas individuales
- **Reportes diarios/semanales**: Generar reportes resumidos del tiempo dedicado
- **Generación de facturas**: Crear facturas desde entradas de tiempo con plantillas personalizables
- **Gráficos de productividad**: Visualizar a dónde va tu tiempo con gráficos interactivos
