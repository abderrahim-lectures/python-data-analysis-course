# Compositor de Música con IA

## Lo que construirás

- Genera melodías MIDI a partir de entradas de estilo o semilla
- Aplica transferencia de estilo musical entre diferentes géneros
- Crea acompañamiento armónico para melodías existentes
- Exporta composiciones como archivos MIDI para usar en cualquier DAW

## Características

- **Transferencia de estilo** — Genera música en el estilo de diferentes géneros y artistas
- **Generación de melodías** — Crea melodías originales a partir de notas semilla o estados de ánimo
- **Acompañamiento armónico** — Agrega progresiones de acordes y pistas de respaldo
- **Exportación MIDI** — Guarda composiciones como archivos MIDI estándar
