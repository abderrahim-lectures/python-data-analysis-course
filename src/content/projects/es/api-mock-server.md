# Servidor Mock de API

## Lo que construirás

- Un servidor mock que lee especificaciones OpenAPI y Swagger para generar APIs realistas
- Proporcionar generación de datos realistas basada en definiciones de esquema
- Simular latencia de red y escenarios de error para pruebas
- Grabar y reproducir interacciones reales de API para desarrollo offline

## Características

- **Generación de datos realistas**: Generar datos mock que coincidan con tipos y restricciones del esquema
- **Simulación de latencia**: Agregar retrasos configurables para simular condiciones reales de red
- **Grabación de escenarios**: Grabar interacciones reales de API y reproducirlas como mocks
- **Modo proxy**: Reenviar requests a un backend real mientras se registran las respuestas

## Objetivos adicionales

- [ ] Agregar un dashboard web para gestionar endpoints mock y datos
- [ ] Implementar pruebas de contrato entre frontend y servidor mock
- [ ] Construir un servidor mock compartido para colaboración en equipo
