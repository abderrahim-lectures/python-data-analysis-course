# Constructor de Pipeline ETL

## Lo que construirás

- Extrae datos de APIs, bases de datos y sistemas de archivos automáticamente
- Aplica transformaciones que incluyen limpieza, agregación y enriquecimiento
- Carga datos procesados en bases de datos objetivo o almacenes de datos
- Programa pipelines con cron y maneja fallos con gracia

## Características

- **Extracción multi-fuente** — Saca datos de REST APIs, bases de datos SQL y archivos
- **Transformación de datos** — Limpia, agrega y enriquece datos en etapas del pipeline
- **Carga incremental** — Procesa solo registros nuevos o modificados para eficiencia
- **Lógica de reintento** — Maneja fallos transitorios con reintento automático y backoff

## Objetivos adicionales

- [ ] Agregar panel web para monitorear salud del pipeline
- [ ] Implementar verificaciones de calidad de datos entre etapas del pipeline
- [ ] Crear un mercado de conectores para fuentes contribuidas por la comunidad
