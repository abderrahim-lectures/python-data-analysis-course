# API de Scraping Web

## Lo que construirás
- Un servicio de scraping web escalable con puntos finales de API
- Un sistema de rotación de proxy para distribución de solicitudes
- Un motor de limitación de tasa para rastreo respetuoso
- Un pipeline de extracción de datos estructurados con selectores CSS/XPath

## Características
- **Rotación de proxy** — Distribuye solicitudes entre múltiples servidores proxy
- **Limitación de tasa** — Controla frecuencia de solicitudes para evitar bloqueos
- **Selectores CSS/XPath** — Extrae datos con selección precisa de elementos
- **Salida JSON** — Devuelve datos estructurados en formatos estándar
