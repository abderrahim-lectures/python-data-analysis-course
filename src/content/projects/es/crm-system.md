# Sistema CRM

## Lo que construirás
- Una base de datos de gestión de contactos con búsqueda y filtrado
- Un rastreador de pipeline de negocios con flujo de trabajo por etapas
- Un sistema de integración de correo electrónico para registrar comunicaciones
- Una línea de tiempo de actividad para cada contacto y negocio

## Características
- **Base de datos de contactos** — Almacena y busca contactos con campos personalizados
- **Pipeline de negocios** — Rastrea negocios a través de etapas personalizables
- **Seguimiento de correo** — Registra correos enviados y recibidos automáticamente
- **Registro de actividades** — Registra llamadas, reuniones y notas por contacto
