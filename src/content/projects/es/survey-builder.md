# Constructor de Encuestas

## Lo que construirás
- Una interfaz de creación de encuestas con construcción de preguntas por arrastrar y soltar
- Un motor de lógica de ramificación para flujo de preguntas condicionales
- Un sistema de recolección de respuestas con resultados en tiempo real
- Un pipeline de análisis estadístico para datos de encuestas

## Características
- **Tipos de preguntas** — Opción múltiple, escalas de calificación, texto abierto y más
- **Lógica de ramificación** — Muestra u oculta preguntas según respuestas anteriores
- **Analíticas de respuestas** — Visualiza resultados con gráficos y tabulaciones cruzadas
- **Exportar a CSV** — Descarga datos sin procesar para análisis externo

## Metas adicionales
- [ ] Agregar prueba A/B para variantes de encuestas
- [ ] Construir un sistema de gestión de paneles para distribución dirigida
- [ ] Implementar análisis de lenguaje natural para respuestas abiertas
