# Almacén de Features

## Lo que construirás

- Un repositorio centralizado de features para modelos de machine learning
- Calcular features una vez y servirlas tanto para entrenamiento como inferencia
- Versionar features y compartirlas entre equipos y proyectos
- Proporcionar servicio online y offline con corrección en el tiempo

## Características

- **Versionado de features**: Rastrear y gestionar versiones de features con el tiempo
- **Servicio online/offline**: Servir features para inferencia en tiempo real y entrenamiento por lotes
- **Corrección en el tiempo**: Asegurar consistencia de features para datos de entrenamiento
- **Compartición**: Compartir features calculadas entre equipos y proyectos
