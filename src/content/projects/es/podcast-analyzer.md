# Analizador de Podcasts

## Lo que construirás
- Un pipeline de transcripción para archivos de audio de podcasts
- Un motor de resumen para contenido de episodios
- Un sistema de detección de temas para organización de contenido
- Una herramienta de extracción de invitados para identificación de hablantes

## Características
- **Transcripción** — Convierte audio hablado a transcripciones de texto precisas
- **Resumen** — Genera resúmenes concisos de episodios y puntos clave
- **Detección de temas** — Identifica temas principales y discusiones
- **Extracción de invitados** — Identifica y lista participantes del episodio
