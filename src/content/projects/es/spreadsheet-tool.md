# Procesador de Hojas de Cálculo

## Lo que construirás

- Una herramienta que lee y escribe archivos CSV y Excel programáticamente
- Aplicar fórmulas y cálculos a datos de hojas de cálculo
- Generar gráficos y tablas dinámicas desde datos en bruto
- Validar datos contra reglas y restricciones definidas

## Características

- **Motor de fórmulas**: Aplicar fórmulas al estilo Excel para calcular valores derivados
- **Generación de gráficos**: Crear gráficos de barras, líneas y dispersión desde datos
- **Tablas dinámicas**: Resumir y analizar datos con tablas dinámicas flexibles
- **Validación de datos**: Definir y aplicar reglas para calidad de datos
