# Rastreador de Experimentos

## Lo que construirás
- Un sistema de registro de experimentos de ML con captura automática de métricas
- Una interfaz de rastreo de parámetros para gestión de hiperparámetros
- Un sistema de almacenamiento de artefactos para modelos y conjuntos de datos
- Un panel de comparación para analizar resultados de experimentos

## Características
- **Rastreo de métricas** — Registra precisión, pérdida y métricas personalizadas con el tiempo
- **Registro de parámetros** — Registra cada hiperparámetro para reproducibilidad completa
- **Almacenamiento de artefactos** — Guarda puntos de control del modelo, conjuntos de datos y salidas generadas
- **Vistas de comparación** — Comparación lado a lado de múltiples experimentos
