# Verificador de Síntomas

Entiende tus síntomas.

## Lo que construirás

- Una interfaz interactiva de entrada de síntomas
- Una base de datos completa de síntomas y condiciones
- Evaluación de severidad con puntuación de urgencia
- Recomendaciones de salud y orientación de próximos pasos

## Características

- **Base de datos de síntomas** — Catálogo buscable de síntomas comunes
- **Evaluación de severidad** — Clasificar intensidad y duración de síntomas
- **Motor de recomendaciones** — Sugerir autocuidado o asistencia profesional
- **Urgencia de visita** — Determinar cuándo buscar atención inmediata

## Metas adicionales

- [ ] Añadir seguimiento de historial de síntomas a lo largo del tiempo
- [ ] Implementar mapa corporal para entrada basada en ubicación
- [ ] Construir integración con programación de telemedicina

> **Nota:** Esto es solo para fines educativos y no constituye asesoramiento médico.
