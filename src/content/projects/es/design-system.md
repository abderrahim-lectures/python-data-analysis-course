# Generador de Sistema de Diseño

## Lo que construirás
- Un pipeline de generación de tokens de diseño desde entradas de marca
- Un sistema de paleta de colores con verificación de contraste de accesibilidad
- Un generador de escala tipográfica con tamaños responsivos
- Un sistema de exportación de variables CSS para frameworks frontend

## Características
- **Generación de paleta de colores** — Crea paletas armónicas a partir de colores base
- **Escala tipográfica** — Genera escalas consistentes de tamaño de fuente y espaciado
- **Tokens de componentes** — Define tokens de diseño para botones, tarjetas y formularios
- **Exportación CSS** — Salida de propiedades CSS personalizadas listas para usar
