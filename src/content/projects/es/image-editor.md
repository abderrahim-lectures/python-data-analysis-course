# Editor de Imágenes

## Lo que construirás
- Un pipeline de procesamiento de imágenes con biblioteca de filtros y efectos
- Un motor de procesamiento por lotes para operaciones masivas de imágenes
- Un sistema de conversión de formato para compatibilidad entre plataformas
- Una herramienta de marca de agua para marca y protección

## Características
- **Biblioteca de filtros** — Aplica desenfoque, nitidez, brillo y ajustes de color
- **Procesamiento por lotes** — Procesa miles de imágenes con un solo comando
- **Conversión de formato** — Convierte entre PNG, JPEG, WebP y más
- **Marcas de agua** — Agrega marcas de agua de texto o imagen con posicionamiento personalizado
