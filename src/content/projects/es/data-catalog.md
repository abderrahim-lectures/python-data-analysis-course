# Catálogo de Datos

## Lo que construirás

- Un catálogo de metadatos con búsqueda que indexa conjuntos de datos, esquemas y linaje de datos
- Conectarse a bases de datos, escanear tablas y construir un catálogo consultable
- Rastrear la propiedad, tipos y relaciones de conjuntos de datos en tu organización
- Proporcionar una única fuente de verdad para el descubrimiento de datos

## Características

- **Descubrimiento automático**: Escanear e indexar conjuntos de datos automáticamente desde múltiples fuentes
- **Seguimiento de evolución del esquema**: Monitorear cómo cambian los esquemas con el tiempo
- **Linaje de datos**: Visualizar cómo fluyen los datos entre sistemas y transformaciones
- **Búsqueda**: Búsqueda de texto completo en conjuntos de datos, columnas y metadatos
