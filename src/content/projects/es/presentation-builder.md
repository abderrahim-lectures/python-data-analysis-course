# Constructor de Presentaciones

## Lo que construirás

- Una herramienta que convierte Markdown en hermosas presentaciones de diapositivas
- Aplicar temas y transiciones para presentaciones profesionales
- Agregar notas del presentador para guía de presentación
- Exportar diapositivas a PDF para compartir

## Características

- **Sistema de temas**: Elegir entre temas incorporados o crear personalizados
- **Transiciones**: Agregar transiciones animadas entre diapositivas
- **Notas del presentador**: Incluir notas visibles solo para el presentador
- **Exportar a PDF**: Generar versiones PDF de presentaciones

## Objetivos adicionales

- [ ] Agregar soporte para imágenes y videos incrustados
- [ ] Construir un modo de presentación en vivo con interacción de audiencia
- [ ] Implementar edición colaborativa de diapositivas
