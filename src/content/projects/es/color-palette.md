# Generador de Paleta de Colores

## Lo que construirás
- Un motor de teoría del color para generación de paletas armónicas
- Un verificador de contraste de accesibilidad para cumplimiento WCAG
- Un sistema de exportación para múltiples estándares de formato de color
- Un historial de paletas para guardar combinaciones previas

## Características
- **Generación armónica** — Crea paletas complementarias, análogas y triádicas
- **Verificación de contraste** — Valida combinaciones de colores contra directrices WCAG
- **Formatos de exportación** — Salida como CSS, configuración de Tailwind, JSON o variables SCSS
- **Historial de paletas** — Guarda y revisa esquemas de colores generados previamente
