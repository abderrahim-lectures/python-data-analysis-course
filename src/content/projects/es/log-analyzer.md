# Analizador y Visualizador de Logs

## Lo que construirás

- Una herramienta que ingiere archivos de log en múltiples formatos y proporciona búsqueda unificada
- Detectar patrones y anomalías en millones de líneas de log
- Visualizar datos de log en líneas de tiempo y gráficos de frecuencia
- Definir reglas de alerta para patrones de error críticos

## Características

- **Detección de patrones**: Identificar automáticamente patrones de error recurrentes y anomalías
- **Filtrado por nivel de log**: Filtrar logs por severidad, fuente, timestamp y campos personalizados
- **Visualización de línea de tiempo**: Graficar eventos de log en líneas de tiempo interactivas
- **Reglas de alerta**: Definir reglas que activen notificaciones en patrones específicos

## Objetivos adicionales

- [ ] Agregar soporte para logs en streaming desde Kafka o RabbitMQ
- [ ] Construir una UI web para monitoreo de logs en tiempo real
- [ ] Implementar agregación de logs entre múltiples servicios
