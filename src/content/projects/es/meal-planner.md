# Planificador de Comidas

Come saludablemente con comidas planificadas.

## Lo que construirás

- Una interfaz de calendario para planificación semanal de comidas
- Análisis nutricional para cada comida y totales diarios
- Una base de datos de recetas buscable con favoritos
- Generación automática de listas de compras desde comidas planificadas

## Características

- **Análisis nutricional** — Rastrear calorías, macro y micronutrientes
- **Base de datos de recetas** — Buscar, guardar y calificar tus recetas favoritas
- **Listas de compras** — Generación automática desde planes de comidas
- **Restricciones dietéticas** — Filtrar recetas por alergias y preferencias

- [ ] Implementar programación de preparación de comidas con cocción por lotes
