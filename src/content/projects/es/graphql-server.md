# Servidor de API GraphQL

## Lo que construirás

- Un esquema GraphQL completo con consultas, mutaciones y suscripciones
- Usa DataLoader para agrupar consultas de base de datos y prevenir problemas N+1
- Proporciona suscripciones en tiempo real para actualizaciones de datos en vivo
- Incluye GraphQL Playground para exploración interactiva de la API

## Características

- **Agrupación DataLoader** — Previene consultas N+1 con agrupación automática de solicitudes
- **Suscripciones en tiempo real** — Empuja actualizaciones en vivo a clientes conectados
- **Diseño esquema-primero** — Define tu esquema API antes de escribir resolutores
- **GraphQL Playground** — IDE interactivo para explorar y probar tu API

## Objetivos adicionales

- [ ] Agregar middleware de autenticación y autorización
- [ ] Implementar schema stitching para microservicios
- [ ] Crear una puerta de enlace de suscripciones para escalar funciones en tiempo real
