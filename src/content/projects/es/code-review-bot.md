# Bot de Revisión de Código con IA

## Lo que construirás

- Vigila pull requests de GitHub y analiza cambios de código con un LLM
- Publica comentarios de revisión directamente en diffs con sugerencias accionables
- Aplica guías de estilo de código y detecta patrones comunes de errores
- Rastrea métricas de calidad de código a lo largo del tiempo en tu proyecto

## Características

- **Análisis de diffs** — Entiende el contexto de los cambios y revisa de manera significativa
- **Detección de errores** — Detecta errores comunes como referencias nulas y condiciones de carrera
- **Aplicación de estilo** — Aplica y enforce estándares de codificación personalizados automáticamente
- **Escaneo de seguridad** — Identifica vulnerabilidades potenciales en código nuevo
