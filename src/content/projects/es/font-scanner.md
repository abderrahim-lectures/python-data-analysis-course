# Herramienta de Emparejamiento de Fuentes

## Lo que construirás
- Un motor de coincidencia de fuentes basado en estilo y legibilidad
- Un renderizador de vista previa en vivo para probar combinaciones de fuentes
- Una integración con Google Fonts para acceso a fuentes web gratuitas
- Un generador de cadenas de alternativas para pilas de fuentes seguras para web

## Características
- **Algoritmos de emparejamiento** — Combina fuentes por contraste, peso y armonía de estilo
- **Vista previa en vivo** — Ve combinaciones de fuentes renderizadas con texto personalizado
- **Integración con Google Fonts** — Accede a miles de fuentes web gratuitas
- **Cadenas de alternativas** — Genera pilas de fuentes multiplataforma
