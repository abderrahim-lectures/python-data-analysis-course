# Motor de Recomendaciones

## Lo que construirás

- Recopila interacciones de usuarios y calcula similitudes entre elementos
- Sirve recomendaciones a través de una API REST limpia
- Maneja escenarios de arranque en frío para nuevos usuarios y elementos
- Soporta pruebas A/B para medir la calidad de las recomendaciones

## Características

- **Enfoque híbrido** — Combina filtrado colaborativo y basado en contenido
- **Manejo de arranque en frío** — Proporciona recomendaciones significativas incluso con datos escasos
- **Actualizaciones en tiempo real** — Actualiza recomendaciones cuando llegan nuevas interacciones
- **Explicabilidad** — Muestra a los usuarios por qué cada elemento fue recomendado
