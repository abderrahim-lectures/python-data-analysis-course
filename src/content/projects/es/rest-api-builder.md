# Constructor de API REST

## Lo que construirás

- Lee un esquema YAML y genera rutas FastAPI completas automáticamente
- Incluye autenticación JWT y control de acceso basado en roles
- Agrega validación Pydantic para todos los cuerpos de solicitudes y respuestas
- Genera documentación OpenAPI lista para uso en producción

## Características

- **Endpoints CRUD automáticos** — Genera rutas de crear, leer, actualizar y eliminar desde esquemas
- **JWT Auth** — Autenticación basada en tokens con soporte de renovación
- **Validación Pydantic** — Validación automática de solicitudes con mensajes de error claros
- **Documentación OpenAPI** — Documentación interactiva de API generada automáticamente

## Objetivos adicionales

- [ ] Agregar limitación de tasa y restricción de solicitudes
- [ ] Implementar soporte de webhooks para arquitecturas orientadas a eventos
- [ ] Crear herramienta CLI para gestión y despliegue de APIs
