# Analizador SEO

## Lo que construirás
- Un rastreador web que analiza estructura y contenido de páginas
- Un auditor de meta tags para mejores prácticas de SEO
- Un motor de puntuación de rendimiento para métricas de velocidad de página
- Una herramienta de análisis de palabras clave para optimización de contenido

## Características
- **Análisis de meta tags** — Verifica títulos, descripciones y tags de Open Graph
- **Estructura de encabezados** — Valida jerarquía y uso de H1-H6
- **Puntuación de rendimiento** — Mide tiempos de carga y Core Web Vitals
- **Densidad de palabras clave** — Analiza contenido para optimización de palabras clave objetivo
