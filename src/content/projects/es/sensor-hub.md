# Hub de Sensores IoT

Centro central para todos tus sensores.

## Lo que construirás

- Un gateway de recolección de datos de múltiples sensores
- Panel de monitoreo en tiempo real con feeds de sensores en vivo
- Sistema de alertas basado en umbrales
- Almacenamiento y recuperación de datos históricos

## Características

- **Agregación de sensores** — Recolectar datos de temperatura, humedad y movimiento
- **Paneles en tiempo real** — Gráficos y medidores con actualización en vivo
- **Alertas de umbral** — Notificaciones cuando las lecturas excedan rangos seguros
- **Almacenamiento de datos** — Base de datos de series temporales para análisis histórico

## Metas adicionales

- [ ] Añadir soporte de protocolo MQTT para comunicación de sensores
- [ ] Implementar detección de anomalías en flujos de sensores
- [ ] Construir un sistema de complementos para tipos de sensores personalizados
