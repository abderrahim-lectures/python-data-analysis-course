# Generador de Facturas

## Lo que construirás
- Un sistema de creación de facturas basado en plantillas
- Un pipeline de generación de PDF para salida profesional de facturas
- Un sistema de seguimiento de pagos para facturas
- Un programador de facturas recurrentes para facturación por suscripción

## Características
- **Sistema de plantillas** — Diseña plantillas de facturas reutilizables con marca personalizada
- **Generación de PDF** — Crea facturas PDF profesionales al instante
- **Seguimiento de pagos** — Monitorea estado de pago y envía recordatorios
- **Facturas recurrentes** — Programa generación automática de facturas
