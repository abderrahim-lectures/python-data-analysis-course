# Constructor de Chatbots sin Código

## Lo que construirás

- Un editor visual de flujos para diseñar lógica de conversación
- Despliega chatbots en Slack, WhatsApp o web con un clic
- Maneja clasificación de intenciones y extracción de entidades automáticamente
- Gestiona contexto de conversación a través de interacciones multi-turno

## Características

- **Editor visual** — Diseña flujos de conversación con interfaz de arrastrar y soltar
- **Motor NLU** — Clasificación de intenciones y extracción de entidades integradas
- **Gestión de contexto** — Mantiene estado de conversación entre múltiples turnos
- **Despliegue multi-canal** — Publica en Slack, WhatsApp, web y más

- [ ] Agregar panel de analíticas que muestre métricas de conversación
- [ ] Implementar transferencia a humano para conversaciones complejas
- [ ] Soportar datos de entrenamiento personalizados para intenciones específicas del dominio
