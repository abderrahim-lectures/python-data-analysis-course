# Formateador de Código

## Lo que construirás

- Un formateador que lee código Python y lo reformatea consistentemente
- Imponer un estilo consistente en todo tu equipo sin configuración
- Ordenar imports, normalizar strings e aplicar indentación consistente
- Generar diffs mostrando exactamente qué cambió

## Características

- **Formato sin configuración**: Funciona fuera de la caja con valores predeterminados sensatos
- **Ordenamiento de imports**: Organizar y ordenar statements de import automáticamente
- **Normalización de strings**: Imponer estilos de comillas consistentes y secuencias de escape
- **Salida de diff**: Mostrar exactamente qué cambios se hicieron en cada archivo
