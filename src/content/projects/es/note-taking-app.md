# App de Notas en Markdown

## Lo que construirás

- Una aplicación basada en terminal para almacenar y organizar notas en Markdown
- Buscar en todas las notas con búsqueda de texto completo
- Organizar notas con etiquetas y categorías
- Exportar notas a PDF para compartir

## Características

- **Búsqueda de texto completo**: Buscar en todas las notas instantáneamente
- **Sistema de etiquetas**: Organizar notas con etiquetas flexibles
- **Vista previa de Markdown**: Renderizar Markdown con resaltado de sintaxis en la terminal
- **Exportar a PDF**: Generar documentos PDF desde notas Markdown
