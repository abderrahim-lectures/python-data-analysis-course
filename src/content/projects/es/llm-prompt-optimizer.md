# Optimizador de Prompts LLM

## Lo que construirás

- Una herramienta CLI que toma prompts crudos y genera variantes optimizadas
- Prueba automáticamente patrones few-shot, cadena de pensamiento y basados en roles
- Compara variantes de prompts usando métricas de puntuación integradas
- Exporta prompts optimizados para flujos de trabajo LLM posteriores

## Características

- **Auto-optimización** — Genera y clasifica variantes de prompts automáticamente
- **Pruebas A/B** — Compara prompts lado a lado con la misma entrada
- **Inyección few-shot** — Selecciona e inserta ejemplos relevantes automáticamente
- **Métricas de puntuación** — Mide precisión, consistencia y eficiencia de tokens
