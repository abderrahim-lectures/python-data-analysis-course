# Pipeline AutoML

## Lo que construirás

- Preprocesamiento automático de datos, selección de características y elección de modelos
- Ajuste de hiperparámetros usando optimización bayesiana
- Compara más de 10 algoritmos y genera scripts Python listos para producción
- Exporta modelos entrenados con pipelines de preprocesamiento adjuntos

## Características

- **Preprocesamiento automático** — Maneja valores faltantes, codificación y escalado automáticamente
- **Selección de modelos** — Compara algoritmos como XGBoost, Random Forest y redes neuronales
- **Optimización bayesiana** — Ajusta hiperparámetros eficientemente con búsqueda inteligente
- **Exportación de código** — Genera scripts Python limpios listos para despliegue en producción

## Objetivos adicionales

- [ ] Agregar panel web para monitorear ejecuciones de entrenamiento
- [ ] Implementar soporte para métricas personalizadas de evaluación específica del dominio
- [ ] Crear ingeniería automática de características con polinomiales e interacciones
