# Constructor de Newsletters

## Lo que construirás
- Una plataforma de creación de newsletters usando plantillas Markdown
- Un sistema de gestión de suscriptores con segmentación de listas
- Un motor de entrega de correo electrónico con seguimiento de aperturas
- Un marco de prueba A/B para optimización de asuntos

## Características
- **Plantillas Markdown** — Escribe newsletters en Markdown con vista previa HTML
- **Listas de suscriptores** — Gestiona contactos con etiquetas y segmentación
- **Seguimiento de aperturas** — Monitorea aperturas de correo y clics
- **Asuntos A/B** — Prueba diferentes asuntos para mejor engagement
