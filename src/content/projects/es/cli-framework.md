# Constructor de Framework CLI

## Lo que construirás

- Un framework para construir herramientas CLI profesionales con mínimo código boilerplate
- Soporte de enrutamiento de subcomandos con generación automática de ayuda
- Cargar configuración desde archivos y variables de entorno
- Extender funcionalidad a través de una arquitectura de plugins

## Características

- **Enrutamiento de subcomandos**: Organizar comandos en subcomandos con agrupación natural
- **Generación automática de ayuda**: Generar texto de ayuda automáticamente desde docstrings y type hints
- **Arquitectura de plugins**: Extender funcionalidad a través de plugins cargables
- **Carga de configuración**: Cargar configuración desde YAML, JSON, TOML y variables de entorno

## Objetivos adicionales

- [ ] Agregar completado de shell para bash, zsh y fish
- [ ] Implementar un framework de testing para comandos CLI
- [ ] Construir un sistema de middleware basado en decoradores para preprocesamiento
