# Analizador de Datos Geoespaciales

## Lo que construirás

- Una herramienta que procesa datos de latitud y longitud para análisis geográfico
- Encontrar patrones en datos geográficos mediante clustering y visualización
- Generar mapas de calor y cálculos de distancia
- Optimizar rutas entre múltiples puntos

## Características

- **Clustering espacial**: Agrupar puntos cercanos usando DBSCAN y K-means
- **Generación de mapas de calor**: Crear mapas de calor a partir de datos de puntos geográficos
- **Cálculos de distancia**: Calcular distancias entre coordenadas usando múltiples fórmulas
- **Optimización de rutas**: Encontrar rutas óptimas a través de múltiples waypoints
