# Hub de Automatización del Hogar

Haz tu hogar inteligente.

## Lo que construirás

- Un motor de automatización basado en reglas con activadores y acciones
- Gestión de horarios para automatización basada en tiempo
- Detección de presencia usando datos de red y sensores
- Integración de comandos de voz para control manos libres

## Características

- **Reglas activador-acción** — Crear automatizaciones estilo si-entonces
- **Horarios** — Control de dispositivos con horarios recurrentes
- **Detección de presencia** — Determinar estado en casa/fuera desde teléfono o sensores
- **Integración de voz** — Conectar con asistentes de voz para control manos libres
