# Generador de Pruebas con IA

## Lo que construirás

- Lee código fuente y genera suites de pruebas completas automáticamente
- Detecta casos extremos y condiciones de borde que los desarrolladores suelen pasar por alto
- Crea pruebas basadas en propiedades para funciones matemáticas y de transformación de datos
- Analiza cobertura y sugiere pruebas adicionales para caminos no probados

## Características

- **Generación de pruebas unitarias** — Crea código pytest y unittest a partir de firmas de funciones
- **Detección de casos extremos** — Identifica condiciones de borde y caminos de error
- **Pruebas basadas en propiedades** — Genera pruebas hypothesis para funciones de datos
- **Análisis de cobertura** — Encuentra caminos de código no probados y sugiere nuevas pruebas
