# Rastreador de Linaje de Datos

## Lo que construirás

- Una herramienta que rastrea transformaciones de datos de extremo a extremo en tus sistemas
- Visualizar cómo fluyen los datos desde sistemas fuente hasta dashboards e informes
- Entender de dónde vienen los datos y a dónde van después de cada transformación
- Realizar análisis de impacto cuando cambian los esquemas de origen

## Características

- **Gráficos de linaje visuales**: Gráficos interactivos que muestran el flujo de datos entre sistemas
- **Análisis de impacto**: Determinar qué activos downstream se ven afectados por cambios
- **Seguimiento de cambios**: Monitorear cambios de esquema y datos con el tiempo
- **Mapeo de dependencias**: Mapear dependencias entre tablas, vistas y pipelines

## Objetivos adicionales

- [ ] Agregar soporte para extracción de linaje de dbt, Airflow y Spark
- [ ] Construir una API para consultas de linaje programáticas
- [ ] Implementar informes de impacto automáticos en cambios de esquema
