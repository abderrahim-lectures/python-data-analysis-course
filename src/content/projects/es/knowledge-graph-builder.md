# Constructor de Grafos de Conocimiento

## Lo que construirás

- Extrae entidades nombradas como personas, organizaciones y ubicaciones del texto
- Identifica relaciones entre entidades y las almacena en una base de datos de grafos
- Visualiza grafos de conocimiento con herramientas de exploración interactivas
- Consulta relaciones usando un lenguaje de consulta de grafos

## Características

- **Extracción NER** — Identifica personas, organizaciones, ubicaciones y entidades personalizadas
- **Detección de relaciones** — Descubre relaciones entre entidades extraídas
- **Visualización de grafos** — Explora grafos de conocimiento con diagramas de nodos enlaces interactivos
- **Lenguaje de consulta** — Escribe consultas personalizadas para recorrer y filtrar el grafo

## Objetivos adicionales

- [ ] Agregar soporte para importar desde bases de datos de grafos existentes
- [ ] Implementar resolución de conflictos para menciones de entidades superpuestas
- [ ] Crear una API REST para acceso programático al grafo
