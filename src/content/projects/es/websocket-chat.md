# App de Chat en Tiempo Real

## Lo que construirás

- Un servidor WebSocket con comunicación bidireccional en tiempo real
- Soporte para múltiples salas de chat con flujos de mensajes independientes
- Muestra indicadores de escritura cuando los usuarios están redactando
- Almacena y recupera el historial de mensajes de cada sala

## Características

- **Múltiples salas** — Crea y gestiona espacios de chat separados
- **Indicadores de escritura** — Ve cuando otros usuarios están escribiendo en tiempo real
- **Historial de mensajes** — Desplázate hacia atrás por conversaciones pasadas
- **Reacciones con emoji** — Reacciona a mensajes con respuestas emoji personalizadas

## Objetivos adicionales

- [ ] Agregar cifrado de extremo a extremo para conversaciones privadas
- [ ] Implementar compartir archivos e imágenes dentro de las salas
- [ ] Crear indicadores de presencia que muestren usuarios en línea
