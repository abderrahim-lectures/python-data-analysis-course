# Constructor de Formularios

## Lo que construirás

- Un constructor visual de formularios que genera definiciones de esquema JSON
- Crear formularios complejos sin escribir HTML
- Definir reglas de validación y lógica condicional
- Manejar envíos de formularios con almacenamiento y procesamiento

## Características

- **Drag-and-drop**: Construir formularios visualmente con interfaz drag-and-drop
- **Reglas de validación**: Definir validación del lado del cliente y del servidor
- **Lógica condicional**: Mostrar u ocultar campos basado en la entrada del usuario
- **Almacenamiento de envíos**: Almacenar y gestionar envíos de formularios

## Objetivos adicionales

- [ ] Agregar integración con bases de datos y hojas de cálculo populares
- [ ] Construir soporte de webhooks para notificaciones de envío en tiempo real
- [ ] Implementar formularios de múltiples pasos con seguimiento de progreso
