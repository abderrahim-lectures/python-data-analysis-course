# Gestor de Citas

## Lo que construirás
- Un gestor de bibliografías que almacena y organiza referencias
- Un formateador automático que soporta estilos APA, MLA, Chicago y BibTeX
- Un sistema de importación por DOI para recopilación rápida de referencias
- Una extensión de navegador para capturar citas de páginas web

## Características
- **Múltiples estilos de formato** — Cambia entre APA, MLA, Chicago y BibTeX al instante
- **Importar por DOI** — Agrega referencias ingresando un DOI o URL
- **Extensión de navegador** — Captura citas directamente de sitios web académicos
- **Integración con Word** — Inserta citas formateadas en documentos
