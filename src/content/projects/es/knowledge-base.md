# Base de Conocimiento Personal

## Lo que construirás

- Un sistema de notas enlazadas inspirado en el método Zettelkasten
- Conectar ideas con enlaces bidireccionales y backlinks
- Visualizar tu conocimiento como un grafo interactivo
- Buscar en todas las notas con búsqueda de texto completo

## Características

- **Enlaces bidireccionales**: Enlazar notas entre sí y ver conexiones automáticamente
- **Visualización de grafo de conocimiento**: Explorar tu conocimiento como un grafo interactivo
- **Búsqueda de texto completo**: Buscar en todas las notas instantáneamente
- **Sistema de etiquetas**: Organizar notas con etiquetas y categorías flexibles

## Objetivos adicionales

- [ ] Agregar sugerencias de notas con IA basadas en similitud de contenido
- [ ] Implementar plantillas de notas para diferentes tipos de conocimiento
- [ ] Construir un sistema de repetición espaciada para repaso
