# Motor de Wiki

## Lo que construirás

- Un sistema de wiki ligero construido sobre páginas en Markdown
- Rastrear historial de versiones para cada página con soporte completo de diff
- Buscar en todas las páginas y navegar con backlinks
- Permitir edición colaborativa para documentación de equipo

## Características

- **Versionado de páginas**: Rastrear cada cambio con historial de versiones completo
- **Backlinks**: Navegar entre páginas relacionadas automáticamente
- **Búsqueda**: Búsqueda de texto completo en todas las páginas de wiki
- **Edición colaborativa**: Múltiples usuarios pueden editar páginas simultáneamente

## Objetivos adicionales

- [ ] Agregar edición colaborativa en tiempo real con transformación operacional
- [ ] Implementar controles de acceso y permisos de páginas
- [ ] Construir una UI web con vista previa en vivo y resaltado de sintaxis
