# Meal Planner

Eat healthy with planned meals.

## What You'll Build

- A weekly meal planning calendar interface
- Nutrition analysis for each meal and daily totals
- A searchable recipe database with favorites
- Automatic grocery list generation from planned meals

## Features

- **Nutrition analysis** — Track calories, macros, and micronutrients
- **Recipe database** — Search, save, and rate your favorite recipes
- **Grocery lists** — Auto-generate shopping lists from meal plans
- **Dietary restrictions** — Filter recipes by allergies and preferences

- [ ] Add barcode scanning for packaged foods
