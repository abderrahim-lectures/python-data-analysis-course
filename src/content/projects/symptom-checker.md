# Symptom Checker

Understand your symptoms.

## What You'll Build

- An interactive symptom input interface
- A comprehensive symptom-to-condition database
- Severity assessment with urgency scoring
- Health recommendations and next-step guidance

## Features

- **Symptom database** — Searchable catalog of common symptoms
- **Severity assessment** — Rate symptom intensity and duration
- **Recommendation engine** — Suggest self-care or professional help
- **Visit urgency** — Determine when to seek immediate care

## Stretch Goals

- [ ] Add symptom history tracking over time
- [ ] Implement a body map for location-based input
- [ ] Build integration with telehealth scheduling APIs

> **Note:** This is for educational purposes only and does not provide medical advice.
