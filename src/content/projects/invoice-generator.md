# Invoice Generator

## What You'll Build
- A template-based invoice creation system
- A PDF generation pipeline for professional invoice output
- A payment tracking system for invoices
- A recurring invoice scheduler for subscription billing

## Features
- **Template system** — Design reusable invoice templates with custom branding
- **PDF generation** — Create professional PDF invoices instantly
- **Payment tracking** — Monitor payment status and send reminders
- **Recurring invoices** — Schedule automatic invoice generation

## Stretch Goals
- [ ] Add integration with Stripe and PayPal for online payments
- [ ] Build a multi-currency support system with exchange rates
- [ ] Implement automated tax calculation based on jurisdiction
