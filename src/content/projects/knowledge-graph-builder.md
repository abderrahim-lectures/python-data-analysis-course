# Knowledge Graph Builder

## What You'll Build

- Extract named entities like people, organizations, and locations from text
- Identify relationships between entities and store them in a graph database
- Visualize knowledge graphs with interactive exploration tools
- Query relationships using a graph query language

## Features

- **NER Extraction** — Identify people, organizations, locations, and custom entities
- **Relation Detection** — Discover relationships between extracted entities
- **Graph Visualization** — Explore knowledge graphs with interactive node-link diagrams
- **Query Language** — Write custom queries to traverse and filter the graph

## Stretch Goals

- [ ] Add support for importing from existing graph databases
- [ ] Implement conflict resolution for overlapping entity mentions
- [ ] Build a REST API for programmatic graph access
