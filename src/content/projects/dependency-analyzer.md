# Dependency Analyzer

## What You'll Build

- A tool that scans requirements and poetry files to map your dependency tree
- Find vulnerabilities, outdated packages, and license risks automatically
- Detect unused dependencies that can be safely removed
- Visualize the full dependency tree with interactive graphs

## Features

- **Vulnerability scanning**: Check dependencies against known security advisories
- **License compliance**: Identify licenses and flag compatibility issues
- **Unused detection**: Find dependencies that are installed but never imported
- **Tree visualization**: Generate interactive dependency tree graphs

## Stretch Goals

- [ ] Add support for monitoring dependency updates via GitHub Dependabot
- [ ] Build a CI check that fails on critical vulnerabilities
- [ ] Implement automatic pull request creation for safe upgrades
