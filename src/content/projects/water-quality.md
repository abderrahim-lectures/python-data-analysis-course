# Water Quality Monitor

Ensure your water is safe.

## What You'll Build

- A water test result logging interface
- Parameter tracking for pH, chlorine, hardness, and more
- Trend analysis with historical comparison charts
- Alert system for contamination threshold breaches

## Features

- **Parameter tracking** — Log pH, turbidity, TDS, and chemical levels
- **Trend analysis** — Visualize changes over weeks and months
- **Alert thresholds** — Set safe ranges and receive contamination warnings
- **Historical comparison** — Compare current readings to past results
