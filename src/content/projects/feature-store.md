# Feature Store

## What You'll Build

- A centralized feature repository for machine learning models
- Compute features once and serve them for both training and inference
- Version features and share them across teams and projects
- Provide online and offline serving with point-in-time correctness

## Features

- **Feature versioning**: Track and manage feature versions over time
- **Online/offline serving**: Serve features for real-time inference and batch training
- **Point-in-time correctness**: Ensure features are consistent for training data
- **Sharing**: Share computed features across teams and projects

- [ ] Add a feature discovery UI with search and documentation
- [ ] Implement feature monitoring and freshness tracking
- [ ] Build integration with popular ML frameworks (scikit-learn, PyTorch)
