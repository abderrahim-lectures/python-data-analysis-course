# محرك المدونة بتنسيق Markdown

قم ببناء مولد موقع ثابت يحوّل ملفات Markdown إلى مدونة جميلة.

## ما الذي ستبنيه

أداة سطر أوامر تقوم بما يلي:
- قراءة ملفات `.md` من دليل المنشورات
- تحليل البيانات الوصفية الأمامية (العنوان، التاريخ، الوسوم)
- تحويل Markdown إلى HTML مع تمييز بناء الأكواد
- إنشاء صفحة فهرس مع تصفية حسب الوسوم
- إخراج موقع ثابت كامل

## الميزات

- **تحليل البيانات الوصفية** — بيانات YAML وصفية لكل منشور
- **تمييز بناء الأكواد** — كتل أكواد ملونة
- **نظام الوسوم** — صفحات وسوم تلقائية
- **تغذية RSS** — إنشاء تغذية RSS/Atom صالحة
- **الوضع الداكن** — التبديل بين المظهر الفاتح والداكن

## التقنيات المستخدمة

- Python 3.12+
- مكتبة Markdown للتحويل
- Pygments لتمييز بناء الأكواد
- Jinja2 لقوالب HTML
