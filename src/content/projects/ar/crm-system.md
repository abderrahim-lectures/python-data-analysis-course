# نظام إدارة علاقات العملاء

## ما الذي ستبنيه
- قاعدة بيانات لإدارة جهات الاتصال مع البحث والتصفية
- متتبع صفقات خطوط البيع مع تدفق قائم على المراحل
- نظام تكامل البريد الإلكتروني لتسجيل الاتصالات
- جدول زمني للأنشطة لكل جهة اتصال وصفقة

## الميزات
- **قاعدة بيانات جهات الاتصال** — اخزن وابحث عن جهات الاتصال مع حقول مخصصة
- **خطوط البيع** — تتبع الصفقات عبر مراحل قابلة للتخصيص
- **تتبع البريد الإلكتروني** — سجّل رسائل البريد المرسلة والمستلمة تلقائيًا
- **تسجيل الأنشطة** — سجّل المكالمات والاجتماعات والملاحظات لكل جهة اتصال
