# مدير الأسرار

## ما ستبنيه

- أداة تشفير الأسرار المخزنة باستخدام تشفير AES-256
- تدوير مفاتيح API وكلمات المرور تلقائياً حسب الجدول الزمني
- الحفاظ على سجل تدقيق كامل لجميع الوصولات للأسرار
- مشاركة الأسرار بشكل آمن داخل الفرق مع ضوابط الوصول

## الميزات

- **تشفير AES-256**: تشفير جميع الأسرار بتشفير عسكري المستوى
- **التدوير التلقائي**: تدوير الأسرار على جداول زمنية قابلة للتكوين
- **سجل التدقيق**: تتبع كل وصول وتعديل للأسرار
- **مشاركة الفريق**: مشاركة الأسرار بشكل آمن مع ضوابط وصول قائمة على الأدوار
