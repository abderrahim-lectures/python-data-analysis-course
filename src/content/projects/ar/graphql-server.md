# خادم GraphQL API

## ما الذي ستوم ببنائه

- مخطط GraphQL كامل مع استعلامات وmutates واشتراكات
- استخدام DataLoader لدمج استعلامات قاعدة البيانات ومنع مشاكل N+1
- تقديم اشتراكات مباشرة لتحديثات البيانات الحية
- تضمين GraphQL Playground لاستكشاف API التفاعلي

## الميزات

- **دمج DataLoader** — منع استعلامات N+1 مع دمج الطلبات التلقائي
- **اشتراكات مباشرة** — دفع تحديثات حية للعملاء المتصلين
- **تصميم مخطط أول** — تعريف مخطط API قبل كتابة المحللات
- **GraphQL Playground** — IDE تفاعلي لاستكشاف واختبار API
