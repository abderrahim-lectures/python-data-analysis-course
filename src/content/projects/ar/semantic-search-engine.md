# محرك بحث دلالي

## ما الذي ستوم ببنائه

- محرك بحث قائم على المتجهات يفهم الاستعلامات باللغة الطبيعية
- فهرسة أي مجموعة مستندات باستخدام التضمينات للتشابه الدلالي
- تقديم نتائج مجمّعة مع شرح لكل نتيجة مطابقة
- دعم البحث الهجين يجمع بين الكلمات المفتاحية والبحث الدلالي

## الميزات

- **البحث بالتجه** — البحث بالمعنى باستخدام التضمينات الكثيفة
- **الوضع الهجين** — دمج مطابقة الكلمات المفتاحية مع التشابه الدلالي لأفضل النتائج
- **النتائج المجمّعة** — تصفية واستكشاف النتائج حسب التصنيف أو التاريخ أو الصلة
- **وضع الشرح** — فهم سبب عود كل نتيجة وطريقة مطابقتها
