# لوحة بيانات الطقس

قم ببناء لوحة بيانات طرفية جميلة لبيانات الطقس.

## ما الذي ستبنيه

تطبيق سطر أوامر يقوم بما يلي:
- جلب بيانات الطقس الحالية من واجهة برمجة Open-Meteo
- عرض تنبؤات 7 أيام مع أيقونات
- عرض رسوم بيانية لدرجة الحرارة بالساعة
- مقارنة الطقس بين مدن متعددة
- العمل بدون اتصال بالكامل بعد أول جلب

## الميزات

- **بيانات في الوقت الفعلي** — الظروف الحالية لأي إحداثيات
- **رسوم التنبؤ** — رسوم بيانية لدرجة الحرارة بأسلوب ASCII
- **مقارنة المدن** — عرض جانبي للطقس
- **التخزين المؤقت** — تجنب استدعاءات API غير الضرورية
- **تبديل الوحدات** — التبديل بين الوحدات المختصرة والإمبريالية

## التقنيات المستخدمة

- Python 3.12+
- httpx لاستدعاءات API
- Rich لواجهة الطرفية
- Matplotlib لإنشاء الرسوم البيانية
