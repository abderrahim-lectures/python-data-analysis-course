# محرك Wiki

## ما ستبنيه

- نظام Wiki خفيف الوزن مبني على صفحات Markdown
- تتبع سجل الإصدارات لكل صفحة مع دعم Diff الكامل
- البحث عبر جميع الصفحات والتنقل بالروابط العكسية
- تمكين التحرير التعاوني لتوثيق الفريق

## الميزات

- **إصدار الصفحات**: تتبع كل تغيير مع سجل إصدارات كامل
- **الروابط العكسية**: التنقل بين الصفحات ذات الصلة تلقائياً
- **البحث**: بحث كامل النص عبر جميع صفحات Wiki
- **التحرير التعاوني**: يمكن لمستخدمين متعددين تحرير الصفحات في نفس الوقت

## أهداف إضافية

- [ ] إضافة تحرير تعاوني فوري مع تحويل تشغيلي
- [ ] تنفيذ ضوابط الوصول وصلاحيات الصفحات
- [ ] بناء واجهة ويب مع معاينة مباشرة وتمييز بناء الجملة
