# مؤقت التأمل

ابنِ عادة تأمل يومية.

## ما ستفعله

- مؤقت تأمل قابل للتعديل مع أجراس فاصلة
- رسوم بيانية توجيهية لتمارين التنفس
- سجل تاريخ الجلسات مع المدة والنوع
- تتبع السلسلة مع تحليلات العادة

## الميزات

- **مؤقت مع أجراس** — مدة قابلة للتعديل مع أجراس البداية والنهاية
- **أدلة التنفس** — رسوم متحركة بصرية لتمارين التنفس الصندوقي و4-7-8
- **سجل الجلسات** — تسجيل ومراجعة جلسات التأمل السابقة
- **تتبع السلسلة** — مراقبة الأيام المتتالية والدقائق الإجمالية

## أهداف إضافية

- [ ] إضافة مكتبة أصوات طبيعية وضوضاء بيضاء
- [ ] تطبيق تسجيل المزاج قبل وبعد الجلسات
- [ ] بناء تقارير أسبوعية للتأمل مع رؤى
