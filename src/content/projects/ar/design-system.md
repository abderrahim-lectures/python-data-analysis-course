# مولّد نظام التصميم

## ما الذي ستبنيه
- خط إنشاء رموز التصميم من مدخلات العلامة التجارية
- نظام لوحة ألوان مع فحص تباين إمكانية الوصول
- مولّد مقياس طباعة بأحجام متجاوبة
- نظام تصدير متغيرات CSS لأطر العمل الأمامية

## الميزات
- **إنشاء لوحة الألوان** — أنشئ لوحة ألوان متناغمة من ألوان أساسية
- **مقياس الطباعة** — أنشئ أحجام خطوط ومسافات متسقة
- **رموز المكونات** — حدد رموز التصميم لأزرار وبطاقات ونماذج
- **تصدير CSS** — أخرج خصائص CSS جاهزة للاستخدام
