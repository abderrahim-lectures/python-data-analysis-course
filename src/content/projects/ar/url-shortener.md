# API اختصار الروابط

قم ببناء خدمة اختصار روابط تعمل بالكامل مع تحليلات النقرات.

## ما الذي ستبنيه

واجهة برمجة تطبيقات REST تقوم باختصار الروابط وتتبع ما يلي:
- إجمالي النقرات لكل رابط قصير
- مصادر المراجع
- التوزيع الجغرافي
- بيانات النقرات على مدار الوقت

## الميزات

- **توليد رمز قصير** — ترميز Base62 لروابط مختصرة
- **تتبع النقرات** — تسجيل كل زيارة مع البيانات الوصفية
- **لوحة تحليلات** — تصور أنماط النقرات عبر الوقت
- **تحديد المعدل** — منع سوء الاستخدام مع حدود قابلة للتكوين
- **الألقاب المخصصة** — السماح للمستخدمين باختيار رموزهم القصيرة

## التقنيات المستخدمة

- Python 3.12+
- FastAPI لواجهة برمجة التطبيقات REST
- SQLite للتخزين
- Charts لتصور التحليلات
