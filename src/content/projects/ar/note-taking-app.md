# تطبيق أخذ الملاحظات بتنسيق Markdown

## ما ستبنيه

- تطبيق في الطرفية لتخزين وتنظيم الملاحظات بتنسيق Markdown
- البحث عبر جميع الملاحظات ببحث كامل النص
- تنظيم الملاحظات بالعلامات والفئات
- تصدير الملاحظات إلى PDF للمشاركة

## الميزات

- **بحث كامل النص**: البحث عبر جميع الملاحظات فوراً
- **نظام العلامات**: تنظيم الملاحظات بعلامات مرنة
- **معاينة Markdown**: عرض Markdown مع تمييز بناء الجملة في الطرفية
- **تصدير إلى PDF**: إنشاء مستندات PDF من ملاحظات Markdown

## أهداف إضافية

- [ ] إضافة دعم المزامنة عبر أجهزة متعددة
- [ ] تنفيذ ربط الملاحظات والربط العكسي
- [ ] بناء واجهة ويب للوصول من الأجهزة المحمولة
