# منسق الأكواد

## ما ستبنيه

- منسق مبدئي يقرأ مصدر Python وينسقه بشكل متسق
- فرض أسلوب متسق في جميع أنحاء فريقك بدون أي تكوين
- ترتيب الاستيراد وتطبيع النصوص وتطبيق مIndentation المتسق
- إنشاء diffs تُظهر بالضبط ما الذي تغير

## الميزات

- **تنسيق بدون تكوين**: يعمل مباشرة مع إعدادات افتراضية معقولة
- **ترتيب الاستيراد**: تنظيم وترتيب عبارات الاستيراد تلقائياً
- **تطبيع النصوط**: فرض أسلوب اقتباس متسق و淘汰 تسلسلات الهروب
- **إخراج Diff**: إظهار التغييرات الدقيقة في كل ملف
