# بوت مراجعة الكود بالذكاء الاصطناعي

## ما الذي ستقوم ببنائه

- مراقبة طلبات الدمج على GitHub وتحليل التغييرات باستخدام LLM
- نشر تعليقات المراجعة مباشرة على الفروقات مع اقتراحات عملية
- فرض إرشادات أسلوب البرمجة واكتشاف أنماط الأخطاء الشائعة
- تتبع مقاييس جودة الكود عبر مشروعك بمرور الوقت

## الميزات

- **تحليل الفروقات** — فهم سياق التغييرات والمراجعة بشكل ذكي
- **اكتشاف الأخطاء** — اكتشاف pitfalls الشائعة مثل مراجع null و raced conditions
- **فرض الأسلوب** — تطبيق ومعايرة معايير البرمجة المخصصة تلقائياً
- **فحص الأمان** — تحديد الثغرات الأمنية المحتملة في الكود الجديد
