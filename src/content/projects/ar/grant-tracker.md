# متتبع طلبات المنح

## ما الذي ستبنيه
- نظام إدارة طلبات المنح مع تتبع المواعيد النهائية
- أداة تخطيط الميزانية لتكاليف تطوير المقترحات
- مساحة عمل تعاونية لأعضاء الفريق والمراجعين
- لوحة حالة تعرض جميع الطلبات النشطة والقيد الانتظار

## الميزات
- **إدارة المواعيد النهائية** — حدد وتتبع مواعيد التسليم مع التذكيرات
- **تخطيط الميزانية** — خصص الأموال عبر مراحل تطوير المقترحات
- **التعاون مع الفريق** — حدد المهام وشارك المستندات مع المراجعين
- **لوحة الحالة** — اعرض تقدم الطلبات ونتائج التمويل بصريًا

## أهداف إضافية
- [ ] أضف تكاملًا مع أنظمة إدارة المنح الجامعية
- [ ] بناء مكتبة قوالب لأقسام المقترحات الشائعة
- [ ] نفّذ فحص الامتثال التلقائي مقابل متطلبات المانحين
