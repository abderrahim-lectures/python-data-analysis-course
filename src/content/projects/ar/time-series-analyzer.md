# محلل السلاسل الزمنية

## ما ستبنيه

- أداة تفكيك السلاسل الزمنية إلى اتجاهات وموسمية وبقايا
- تنبؤ بالقيم المستقبلية باستخدام نماذج ARIMA و Prophet
- اكتشاف الشذوذ في البيانات الزمنية تلقائياً
- تحليل الارتباطات بين سلاسل زمنية متعددة

## الميزات

- **التفكيك التلقائي**: فصل الاتجاهات والموسمية والبقايا تلقائياً
- **تنبؤ ARIMA/Prophet**: إنشاء تنبؤات مع نماذج قابلة للتكوين
- **تحليل الارتباط**: العثور على علاقات بين سلاسل زمنية مختلفة
- **التصدير**: تصدير نتائج التحليل إلى CSV و JSON وتنسيقات التصوير

## أهداف إضافية

- [ ] إضافة لوحة معلومات ويب لاستكشاف السلاسل الزمنية تفاعلياً
- [ ] تنفيذ اكتشاف شذوذ مباشر للتدفق
- [ ] بناء API للتنبؤ للوصول البرمجي
