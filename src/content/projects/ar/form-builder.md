# منشئ النماذج

## ما ستبنيه

- منشئ نماذج مرئي يخرج تعريفات JSON schema
- إنشاء نماذج معقدة بدون كتابة HTML
- تحديد قواعد التحقق والمنطق الشرطي
- معالجة تقديم النماذج مع التخزين والمعالجة

## الميزات

- **السحب والإفلات**: بناء النماذج بشكل مرئي بواجهة سحب وإفلات
- **قواعد التحقق**: تحديد التحقق من جانب العميل والخادم
- **المنطق الشرطي**: إظهار أو إخفاء الحقول بناءً على إدخال المستخدم
- **تخزين التقديم**: تخزين وإدارة تقديمات النماذج

- [ ] بناء دعم Webhook لإشعارات التقديم الفورية
- [ ] تنفيذ نماذج متعددة الخطوات مع تتبع التقدم
