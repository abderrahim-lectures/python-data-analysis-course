# محوّل المستندات

## ما ستبنيه

- محوّل صيغ مستندات عالمي يدعم Markdown و HTML و PDF و DOCX و LaTeX
- تطبيق قوالب أنماط مخصصة للحفاظ على تنسيق متسق
- تحويل المستندات بشكل مجمع لمعالجة كبيرة الحجم
- وراثة وتركيب الأنماط عبر أنواع المستندات

## الميزات

- **دعم صيغ متعددة**: التحويل بين Markdown و HTML و PDF و DOCX و LaTeX
- **قوالب مخصصة**: تطبيق أنماط وسمات مخصصة على المستندات المحولة
- **تحويل مجمع**: معالجة عدة مستندات في آن واحد
- **وراثة الأنماط**: تركيب و إعادة استخدام الأنماط عبر أنواع المستندات
