# محلل SEO

## ما الذي ستبنيه
- زاحف ويب يحلل هيكل الصفحة ومحتواها
- مدقق علامات وصفية لأفضل ممارسات SEO
- محرك درجة أداء لمقياس أوقات تحميل مقاييس Core Web Vitals
- أداة تحليل الكلمات المفتاحية لتحسين المحتوى

## الميزات
- **تحليل العلامات الوصفية** — تحقق من العناوين والأوصاف وعلامات Open Graph
- **هيكل العنوان** — تحقق من تسلسل واستخدام H1-H6
- **درجة الأداء** — قيّم أوقات التحميل ومقاييس Core Web Vitals
- **كثافة الكلمات المفتاحية** — حلل المحتوى لتحسين الكلمات المفتاحية المستهدفة

## أهداف إضافية
- [ ] أضف تحليل الروابط الخلفية ودرجة صلاحيات النطاق
- [ ] بناء تقرير مقارنة SEO مع المنافسين
- [ ] نفّذ اقتراحات إصلاح تلقائية مع ترتيب الأولوية
