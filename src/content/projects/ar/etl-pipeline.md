# منشئ خط أنابيب ETL

## ما الذي ستوم ببنائه

- استخراج البيانات من واجهات البرمجة وقواعد البيانات وأنظمة الملفات تلقائياً
- تطبيق تحويلات تشمل التنظيف والتركيب والتحسين
- تحميل البيانات المعالجة في قواعد بيانات الهدف أو أوعية البيانات
- جدولة خطوط الأنابيب مع cron ومعالجة الأخطاء برحابة

## الميزات

- **استخراج متعدد المصادر** — سحب البيانات من REST APIs وSQL databases والملفات
- **تحويل البيانات** — تنظيف وتركيب وتحسين البيانات في مراحل خط الأنابيب
- **التحميل التدريجي** — معالجة السجلات الجديدة أو المحدثة فقط للكفاءة
- **منطق إعادة المحاولة** — معالجة الأخطاء العابرة مع إعادة تلقائي وتقهقر

## أهداف إضافية

- [ ] إضافة لوحة متابعة لمراقبة صحة خط الأنابيب
- [ ] تنفيذ فحوصات جودة البيانات بين مراحل خط الأنابيب
- [ ] بناء سوق مُوصِلين لمصادر مساهمة المجتمع
