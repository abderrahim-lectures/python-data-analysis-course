# مولّد لوحة الألوان

## ما الذي ستبنيه
- محرك نظرية الألوان لإنشاء لوحة ألوان متناغمة
- فاحص تباين إمكانية الوصول للامتثال لمعايير WCAG
- نظام تصدير لمعايير ألوان متعددة
- متتبع سجل اللوحات للحفاظ على الت_comboination المحفوظة

## الميزات
- **الإنشاء المتناغم** — أنشئ لوحة ألوان مكمّلة ومماثلة وثلاثية
- **فحص التباين** — تحقق من تركيبات الألوان مقابل إرشادات WCAG
- **صيغ التصدير** — أخرج كـ CSS أو Tailwind config أو JSON أو SCSS variables
- **سجل اللوحات** — احفظ واعد م schemes الألوان التي تم إنشاؤها سابقًا

## أهداف إضافية
- [ ] أضف محاكاة عمى الألوان لاختبار إمكانية الوصول
- [ ] بناء أداة استخراج ألوان العلامة التجارية من الصور
- [ ] نفّذ مولّد تدرجات بأوضاع تقسيم مخصصة
