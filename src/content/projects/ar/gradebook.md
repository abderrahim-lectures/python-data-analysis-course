# سجل الدرجات

بسّط إدارة الدرجات.

## ما ستفعله

- نظام إدخال درجات مع دعم الفئات المرجحة
- حساب أوتوماتيكي للمعدل التراكمي عبر الفصلين
- إنشاء كروت درجات مع قوالب قابلة للتعديل
- بوابة أولياء الأمور لعرض تقدم الطلاب

## الميزات

- **التدريج المرجح** — تكوين فئات الواجبات بالأوزان
- **حساب المعدل** — معدل تراكمي وفصلي أوتوماتيكي
- **كروت الدرجات** — إنشاء PDF مع درجات الأحرف والتعليقات
- **دخول الأولياء** — بوابة آمنة لأولياء الأمور لعرض التقدم
