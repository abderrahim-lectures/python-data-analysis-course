# منشئ النشرات الإخبارية

## ما الذي ستبنيه
- منصة إنشاء نشرات إخبارية باستخدام قوالب Markdown
- نظام إدارة المشتركين مع تقسيم القوائم
- محرك توصيل البريد الإلكتروني مع تتبع الفتح
- إطار اختبار A/B لتحسين عناوين البريد

## الميزات
- **قوالب Markdown** — اكتب النشرات الإخبارية بـ Markdown مع معاينة HTML
- **قوائم المشتركين** — أدر جهات الاتصال مع الوسوم والتقسيم
- **تتبع الفتح** — راقب فتح البريد والنقرات
- **عناوين A/B** — اختبر عناوين مختلفة لتفاعل أفضل

## أهداف إضافية
- [ ] أضف أتمتة الحملات المتتالية لت onboard المشتركين
- [ ] بناء محرر مرئي بالسحب والإفلات بجانب Markdown
- [ ] نفّذ تكامل مع مزودي خدمات البريد الإلكتروني الشائعة
