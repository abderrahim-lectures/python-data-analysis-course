# API كاشط الويب

## ما الذي ستبنيه
- خدمة كاشط ويب قابلة للتوسع مع نقاط نهاية API
- نظام تدوير البروكسي لتوزيع الطلبات
- محرك تحديد المعدل للزحف اللائق
- خط استخراج البيانات المنظمة مع selectors CSS/XPath

## الميزات
- **تدوير البروكسي** — وزّع الطلبات عبر خوادم proxy متعددة
- **تحديد المعدل** — تحكّم في تكرار الطلبات لتجنب الحظر
- **CSS/XPath selectors** — استخرج البيانات باستهداف عناصر دقيق
- **إخراج JSON** — أرجع البيانات المنظمة بصيغ قياسية

## أهداف إضافية
- [ ] أضف دعم متصفح headless للصفحات المعروضة بـ JavaScript
- [ ] بناء نظام طلبات queued للوززحف الموزّع
- [ ] نفّذ التمرير التلقائي والتسلسل المتكرر
