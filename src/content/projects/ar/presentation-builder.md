# منشئ العروض التقديمية

## ما ستبنيه

- أداة تحول Markdown إلى عروض شرائح جميلة
- تطبيق السمات والانتقالات لعروض تقديمية احترافية
- إضافة ملاحظات المتحدث لتوجيه العرض
- تصدير الشرائح إلى PDF للمشاركة

## الميزات

- **نظام السمات**: الاختيار من السمات المدمجة أو إنشاء سمات مخصصة
- **الرسوم المتحركة**: إضافة انتقالات متحركة بين الشرائح
- **ملاحظات المتحدث**: تضمين ملاحظات مرئية فقط للمتحدث
- **تصدير PDF**: إنشاء نسخ PDF من عروض الشرائح

- [ ] إضاء دعم للصور والفيديوهات المضمنة
- [ ] بناء وضع عرض مباشر مع تفاعل الجمهور
- [ ] تنفيذ التحرير التعاوني للعروض التقديمية
