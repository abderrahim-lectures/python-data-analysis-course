# سكين الجيش السويسرية للـ JSON

قم ببناء أداة معالجة JSON قوية عبر سطر الأوامر.

## ما الذي ستبنيه

أداة سطر أوامر تقوم بما يلي:
- تنسيق JSON المضغوط بشكل جمالي
- التحقق من بنية JSON مع تحديد مواقع الأخطاء
- الاستعلام عن البيانات باستخدام مسارات التنسيق النقطي
- تحويل JSON باستخدام الفلاتر والخرائط
- التحويل بين JSON وYAML وTOML

## الميزات

- **التنسيق والتدقيق** — تنسيق جمالي مع م indentation قابل للتكوين
- **التحقق** — فحص البنية والإبلاغ عن الأخطاء مع أرقام الأسطر
-** الاستعلام** — تعبيرات المسار بأسلوب JQ (`$.users[*].name`)
- **التحويل** — تصفية وتحويل وتشكيل البيانات
- **التحويل** — التبادل بين JSON وYAML وTOML

## التقنيات المستخدمة

- Python 3.12+
- Click لسطر الأوامر
- PyYAML وtomli لتحويل الصيغ
- Rich للإخراج الملون
