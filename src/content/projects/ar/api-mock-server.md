# خادم تجريبي API

## ما ستبنيه

- خادم تجريبي يقرأ مواصفات OpenAPI و Swagger لإنشاء APIs واقعية
- توفير توليد بيانات واقعية بناءً على تعريفات المخطط
- محاكاة تأخير الشبكة وسيناريوهات الخطأ للاختبار
- تسجيل وتشغيل تفاعلات API حقيقية للتطوير دون اتصال

## الميزات

- **توليد بيانات واقعية**: إنشاء بيانات تجريبية تتطابق مع قيود وأنواع المخطط
- **محاكاة التأخير**: إضافة تأخيرات قابلة للتكوين لمحاكاة ظروف الشبكة الحقيقية
- **تسجيل السيناريوهات**: تسجيل تفاعلات API حقيقية وتشغيلها كبيانات تجريبية
- **وضع الوكيل**: تمرير الطلبات إلى خادم حقيقي مع تسجيل الاستجابات

## أهداف إضافية

- [ ] إضافة لوحة معلومات ويب لإدارة نقاط النهاية التجريبية والبيانات
- [ ] تنفيذ اختبار العقد بين الواجهة الأمامية وخادم تجريبي
- [ ] بناء خادم تجريبي مشترك للتعاون بين الفرق
