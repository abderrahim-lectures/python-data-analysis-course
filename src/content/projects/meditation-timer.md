# Meditation Timer

Build a daily meditation habit.

## What You'll Build

- A customizable meditation timer with interval bells
- Guided breathing exercise visualizations
- Session history with duration and type logging
- Streak tracking with habit analytics

## Features

- **Timer with bells** — Configurable duration with start/end chimes
- **Breathing guides** — Visual animations for box and 4-7-8 breathing
- **Session history** — Log and review past meditation sessions
- **Streak tracking** — Monitor consecutive days and total minutes

## Stretch Goals

- [ ] Add ambient sound library with nature and white noise
- [ ] Implement mood logging before and after sessions
- [ ] Build weekly meditation reports with insights
