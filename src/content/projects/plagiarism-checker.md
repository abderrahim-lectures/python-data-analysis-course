# Plagiarism Checker

Ensure academic integrity.

## What You'll Build

- A text ingestion pipeline for submitted documents
- N-gram based similarity detection engine
- Source identification and citation checking
- Detailed similarity reports with highlighted matches

## Features

- **N-gram matching** — Detect paraphrased and copied content
- **Citation checking** — Verify proper attribution of sources
- **Similarity scoring** — Percentage-based plagiarism assessment
- **Report generation** — PDF reports with highlighted matches
