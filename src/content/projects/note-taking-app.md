# Markdown Note-Taking App

## What You'll Build

- A terminal-based application for storing and organizing notes in Markdown
- Search across all notes with full-text search
- Organize notes with tags and categories
- Export notes to PDF for sharing

## Features

- **Full-text search**: Search across all notes instantly
- **Tag system**: Organize notes with flexible tagging
- **Markdown preview**: Render Markdown with syntax highlighting in the terminal
- **Export to PDF**: Generate PDF documents from Markdown notes

## Stretch Goals

- [ ] Add sync support across multiple devices
- [ ] Implement note linking and backlinks
- [ ] Build a web interface for mobile access
