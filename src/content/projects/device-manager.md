# Device Manager

Control your IoT fleet.

## What You'll Build

- A device registry for onboarding and tracking devices
- Remote configuration management interface
- Over-the-air firmware update system
- Device health monitoring with heartbeat checks

## Features

- **Device registration** — Onboard new devices with metadata
- **Remote config** — Push configuration changes without physical access
- **OTA updates** — Deploy firmware updates to device fleets
- **Health checks** — Monitor uptime, battery, and signal strength
