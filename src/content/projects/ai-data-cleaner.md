# AI Data Cleaner

## What You'll Build

- Profile datasets and identify quality issues automatically
- Suggest and apply fixes for missing values, outliers, and duplicates
- Validate cleaned data against schemas and business rules
- Maintain a full audit trail of all transformations applied

## Features

- **Auto-Detect Issues** — Identify missing values, outliers, duplicates, and format errors
- **Smart Imputation** — Fill missing values using statistical and ML methods
- **Format Normalization** — Standardize dates, currencies, and text formats
- **Audit Trail** — Track every change made to the original dataset

## Stretch Goals

- [ ] Add a web interface for reviewing and approving suggested fixes
- [ ] Implement custom rules engine for domain-specific validation
- [ ] Build integration with popular databases and data warehouses
