# Course Builder

Build and sell online courses.

## What You'll Build

- A course authoring interface for creating structured content
- Module and lesson organization with drag-and-drop
- Built-in quiz builder for knowledge checks
- Student progress tracking and completion certificates

## Features

- **Module editor** — Drag-and-drop course structure builder
- **Quiz builder** — Create assessments with auto-grading
- **Student tracking** — Monitor enrollment, progress, and completion
- **Certificate PDF** — Generate printable completion certificates
