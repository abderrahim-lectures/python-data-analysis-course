# GraphQL API Server

## What You'll Build

- A complete GraphQL schema with queries, mutations, and subscriptions
- Use DataLoader to batch database queries and prevent N+1 problems
- Provide real-time subscriptions for live data updates
- Include a GraphQL Playground for interactive API exploration

## Features

- **DataLoader Batching** — Prevent N+1 queries with automatic request batching
- **Real-Time Subscriptions** — Push live updates to connected clients
- **Schema-First Design** — Define your API schema before writing resolvers
- **GraphQL Playground** — Interactive IDE for exploring and testing your API

## Stretch Goals

- [ ] Add authentication and authorization middleware
- [ ] Implement schema stitching for microservices
- [ ] Build a subscription gateway for scaling real-time features
